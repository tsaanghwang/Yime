# 18u 桌面虚拟样机开发方案与实施计划

日期：2026-10-20。范围：独立桌面触摸键盘实验及其共用的隔离实验室代码。
开发基线为 PR #70 合并后的 `100c734b94e580e81cf2030f293cb0d722ec0756`，包含已合并的 #69 桌面实现。

先完善虚拟样机，再恢复本机手指与触控笔验收准备。18u 是当前唯一主动开发和验证的主区几何；17u 及其 23u 全盘派生配置作为冻结候选保留。冻结不删除来源、配置、回归或历史证据，也不把已有可用功能标为失效。

## 实现方案

1. **几何与尺度**：复用 `internal/touchkeyboard` 的布局、命中和手势状态。把几何配置、真实键距、屏幕像素/毫米校准分别管理；18u 不随窗口大小自动缩键。侧区显示只是视图选择，侧区数字继续绕过编码和选词。
2. **共用实验会话**：将 `cmd/yime-keyboard-lab` 中适合共用的引擎适配、数据清单校验、会话序列和幂等处理提取到实验专用内部包。网页 HTTP 服务和桌面程序调用同一实现；优先采用桌面进程内会话，避免新增运行时服务依赖。维持网页 API 和 #70 行为，实验数据不进入产品默认路径。
3. **桌面中文界面**：在不抢走宿主焦点的窗口内显示组合与候选。候选按当前会话、revision 和稳定 ID 选择，翻页后旧候选动作失效。CN EN 联动输入语言和标点；中文固定 CN 视图，英文保留 Layout 偏好、显式 Shift 大写及 23 个独立禁用空键。主数字、单字符编码标点候选、保留符号入口等沿用当前实验规则。
4. **提交与目标绑定**：组合只在样机内显示，不把未确认 ASCII 写进目标应用。每个动作绑定目标窗口/焦点世代；失焦只取消原组合和手势，迟到响应不能写入新目标。确认文本进入单独的提交适配器，一次性发送并记录事件身份；结果不明、部分发送或失败时停止后续提交，禁止自动重放或自动补发。`SendInput` 返回只证明事件发送情况，真实应用接受必须另行观察。
5. **资源与交付**：便携包携带本身所需的隔离词典、元数据和私有字体，启动校验身份与哈希；不依赖另一已安装产品或系统字体安装。临时运行数据由自身管理，不读取或迁移用户词库。中文完整包的资源准备与 CI 取用方式在打包阶段落实，源码 checkout 和当前英文 CI 包都不是未来中文完整包。

复用现有入口，按受影响代码选择检查。本轮 P1/P2 已运行下列适用检查及完整语料 HTTP 集成测试，桌面包另执行 `--check-data`，未运行向宿主发送输入的 self-test。

python -X utf8 tools/generate_touch_keyboard_profiles.py --check

P2 已把 `internal/keyboardlab` 补入 Go 测试及 `.github/workflows/touch-terminal.yml` 路径过滤与执行入口。需要完整词典的集成验证按 lab README 指定独立数据根执行，记录实际数据身份；缺失数据不得以演示词典冒充通过。原生 `--self-test` 使用自身临时 EDIT 目标，安排在不干扰用户操作的独立验证时段；它不替代真实应用或真人输入。

证据分别标注：静态/单元、浏览器自动化、模拟触摸、受控原生宿主、用户手指、用户触控笔。鼠标或模拟触摸永远不能提升为真人结果。保留 2026-10-19 原始用户报告与范围，不重写历史 `hardwareAcceptance` 字段，也不继承到新的桌面中文版本。

## 冻结候选与后续缩短方案

保留 `main-17u.json`、`full-23u.json`、`17u-provenance.json`、23u 设计源、生成器和历史证据。当前不继续调整 N26/N27 排布，不另开 17u 开发、调优或真人验收路线；普通维护仍保证既有文件及生成校验完整。

后续优先评估从 18u 同一排布派生“缩短 1 毫米”配置，减少独立布局维护。该说法目前未落实为参数定义：若指每 u 键距从 19.05 改为 18.05 mm，则主区宽 324.90 mm；原 17u 为 323.85 mm，两者相差 1.05 mm，不能直接标成相同几何。若指整盘总宽减少 1 mm，则为 341.90 mm。启用该候选前明确缩短作用于键距、键帽还是总宽，再确定高度/间隙处理及实测标准。本轮不需要据此更改 18u 基准。

缩短候选必须保持键身份与编码不变，使用独立 profile 和报告身份；不能借 Ruler 校准按钮伪造缩小后的物理尺寸。即使以后采用替代实现，17u 原方案仍留作历史记录。
