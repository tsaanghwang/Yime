## 3. 手指与笔：窗口内预览

两轮独立执行：第一轮只用真人手指触发测试输入；第二轮只用真实触控笔触发测试输入。启动/文件检查可用鼠标，但每次测试的接触方式必须写清。笔悬停不算按下；单笔无法执行的双触点案例保留阻塞或明确记录“笔＋手指”混合输入，不归入纯笔通过。

双击 `Start Preview.cmd`。等待词典就绪；每个独立案例前点“清空输出”，确认中文、无组合、无修饰键，所需模式由步骤指定。可点“字形 → ID”找音元键。以下 `N08/n` 是物理键 `R06K12`（18u 主区左上坐标 10.25u, 5.25u）；`M03/i` 是 `R05K14`（12.75u, 4.25u）。均用基础层，不按 Shift。坐标从键区左上起，不含工具栏。

| 案例 | 操作 | 期望及必须记录 |
|---|---|---|
| P01 盘面/量尺 | 数清主区键数；实体尺测顶部 100 mm 线和主区左右几何外缘宽度。必要时用 Ruler ±1% 校准，再重测；重启后复测一次 | 100 键、无侧数字区；基准 18u/342.90 mm。记录校准前后两项实测、调整次数和遮挡/裁切；校准本次运行有效，不能借校准实现“缩短 1 mm” |
| P02 三模式中文 | 变码按 N08、M03；全码按 N08、M03、M03、M03；简码按 N08、M03。每模式先记录组合及候选，再点“你” | 原始组合分别 `ni`、`niii`、`ni`；确认前本地输出不变，确认后仅新增一个“你”。没有“你”时停止并记录候选，不能猜别的键 |
| P03 确认/序号 | 每次重新输入对应完整样例；分别点候选、空格、Enter、候选“你”所在的主区序号键 | 点候选或序号得“你”；空格/Enter 得实际首选。记录首选及序号，不假定其固定排序；每次仅确认一次 |
| P04 组合编辑/取消 | 全码输入 `niii`；Backspace 一次，补 M03；Esc。再输入 `niii`，切变码 | 退格后 `nii`，补后 `niii`；Esc 和切模式均取消未确认组合，本地输出不增字 |
| P05 移出取消 | 按住 N08，移出键面，再移回并抬起；对“你”候选同样做一次 | 键或候选均不触发；与一次正常点按对照。记录误触、漏触、是否抬手才触发；不把人工重复点按当“重复 UP”注入测试 |
| P06 翻页/旧触点 | 输入 `ni`，记录第一页；点下一页再上一页。支持双触点时，一指按候选，另一指翻页，再抬第一指 | 页变化可见，旧候选不提交。无下一页或设备不支持并发时记录阻塞和条件；笔混合操作单列 |
| P07 CN/EN/布局 | 中文输入 `ni`，点 CN EN；英文时切 Layout，点英文 `a`，再点 Shift、`a`；切回中文，再返回英文 | 英文输出 `aA`；中文组合暂停保留，中文固定 CN，英文恢复此前 Layout 偏好；几何/颜色不变 |
| P08 修饰键 | 英文无组合：点 Shift 后点 `a`、再点 `a`；手指按住 Shift 用另一指点 `a`；点 Shift 两次再点 `a` | 一次性路径为 `Aa`，按住路径为 `A`，取消修饰后为 `a`。纯笔只做单触点路径；记录修饰状态是否残留 |
| P09 数字/标点 | 无组合点主区 `1`；再输入 `ni` 点有效候选序号；选一个 CSV 标注 `literalEntry:true` 的层，分别在入口开关关闭和开启时操作 | 无组合得 `1`；有候选选对应候选。未标注入口默认关闭，开启才启用；每次记录实际 key ID/层/候选和标点结果，再恢复关闭。非空页缺失序号的无操作分支若未遇到，单列待记录 |
| P10 100 键覆盖 | 按 CSV 逐键检查 CN 基础/Shift 和 EN 基础/Shift；每键前清空组合/修饰，语言与层按列设置；控制键操作后恢复状态 | 每行填写四层观察和证据。23 个 EN 空白键禁用；unsupported/disabled 不应输出。编码键观察组合、控制键观察其功能，不能要求每键输出正文。逐项未测不可算整行通过 |

样例来源见[输入夹具](../../../docs/testing/touch-keyboard/2026-10-20/p6/input-fixture.json)：规范 `ni3` 的四音元 ID 经包内实验投影和共享 `BuildRecord` 派生，未从词典编码反推。CSV 的 `xU/yU` 是 18u 排布坐标，动作列来自固定包盘面；它是核对表，不是输入事件日志。字段中的 `clear` 指取消组合，`input` 在中文可进入组合，`unsupported/disabled` 表示未接入/禁用；对象空值表示无独立该层动作，结合包内指南观察回退行为。

## 4. 手指与笔：真实应用

关闭预览，启动 `Start Keyboard.cmd`。选择本机已有且可隔离临时正文的宿主 A，再选另一个宿主 B（例如可用的记事本/Word）；记录精确版本、位数、权限及当前输入法，仅观察，不切换默认或安装状态。每个宿主、每种输入方式各做一份结果。若应用未安装或无法隔离，记阻塞，不安装补齐。

每次放好文本光标后点键盘“绑定目标”。不在确认瞬间切换应用。下面先确认三模式，再做英文编辑和安全取消：

| 案例 | 操作 | 期望及必须记录 |
|---|---|---|
| H01 绑定前/三模式 | 新开键盘但未绑定时输入完整样例并尝试确认；记录后取消。亲自在 A 正文点光标并绑定，按 P02 三模式各输入/确认一次 | 未绑定不写任何应用；绑定后，确认前宿主不出现预编辑或原始 ASCII，确认后各增加“你”。逐次保存正文证据 |
| H02 英文/编辑 | 空白 A 绑定后，英文输入 `abc`；Left、Backspace、Shift 后点 `x`；再 Ctrl、Home，Shift、End，输入 `q`；再 Backspace | 中间正文 `aXc`，选中整行替换后 `q`，最后空。每次点修饰键后点目标键；记录实际选区。宿主不支持相应快捷键时记差异，不用其他宿主结果代替 |
| H03 Enter | 英文输入 `a`、Enter、`b`；另起空白临时正文做 Shift+Enter；中文有组合时做 Enter/Shift+Enter | 英文换行与软换行由应用解释，记录实际结构；中文确认首选。不能把中文确认当作宿主 Enter，也不要求所有宿主软换行相同 |
| H04 Esc/失焦 | A 已有一次确认的“你”，再输入未确认 `ni`；Esc。重新输入 `ni`，抬起全部触点后亲自切到 B，再回 A | Esc 不向宿主发 Escape；失焦取消未确认组合，A 已确认正文保留，B 无新增，原绑定失效。重新点 A 光标并绑定后可输入 |
| H05 帮助/隐藏 | A 有未确认组合时打开 Help，关闭后观察；重新绑定后输入组合再 Hide，Ctrl+Alt+K 显示 | 各次组合取消、旧目标需重新绑定；A 正文不增字。显示热键被占用时不 Hide，记阻塞；热键的物理键盘辅助应注明，不算纯触摸覆盖 |
| H06 跨目标重绑 | A 确认“你”；在 B 放光标并绑定，确认“你”；回 A 重新绑定后再确认一次 | A 两个“你”，B 一个；每次只写当次绑定目标，不删除旧正文。不要同时按确认和切换焦点 |
| H07 异常恢复（发生时） | 遇到零发送/部分发送/结果不明，停止点按，记录 A/B 实际全文、状态消息和焦点；人工核对后重绑，仅输入一个新的明确字符 | 不自动重放/回滚、不删除已有前缀；新输入只执行一次。没有自然发生异常填“待记录：未触发”，不能把自有 EDIT 注入结果填进来；不人为提权、结束宿主或制造故障 |

显示环境变化/旋转/断开重连目前只保留开发覆盖；本轮不更改用户显示设置来造条件。若自然发生，立即停止输入并记录取消、重绑和重新量尺结果。迟到回包、重复 UP 注入和强制失败留在开发证据栏，不要求用真人动作伪造。

SendInput 无法原子绑定 HWND，前后焦点检查不能证明最后瞬间的全部竞态被排除。任何部分发送或错目标迹象都须保留原始结果、停止该宿主后续提交，进入 P4 修复；本表通过也只覆盖所列设备/应用/操作。
