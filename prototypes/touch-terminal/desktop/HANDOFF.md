### P4 目标绑定与受控宿主结果

- 新增显式 `--host-input --data-dir <完整隔离词典>`。先在目标文本区点光标，再点“绑定目标”；绑定 HWND、焦点 HWND、进程/线程及焦点世代。组合只在键盘内显示，确认回复进入唯一发送适配器。P3 预览仍只使用内存输出。
- 焦点通知、动作抬起和提交前再次验证目标；离开再返回的旧世代、旧候选和重复动作不提交。隐藏、帮助、显示环境变化及关闭取消原组合和手势。失焦仅清理键盘自己的组合，不向新目标发送 Escape 或自动确认。
- 当前引擎调用同步执行；回包到发送边界仍检查焦点世代，消息泵期间拒绝重入。测试在真实回包返回前切换两个自有 EDIT 的焦点，验证迟到回复被丢弃。
- 发送身份在调用 OS 前消耗；零发送、部分/未知结果或发送期间目标变化停止后续提交，只有核对正文后明确重新绑定才能恢复。不重放、补发或删除已经进入宿主的前缀。部分计数的批处理测试只释放实际插入的按下前缀，清理失败也不重试文本。
- 完整词典三模式在自有临时 EDIT 中确认“你”，验证组合不入宿主、候选抬手/重复抬手、Ctrl+Home/Shift+End 替换、退格、取消；英文切换和 literal Enter 单独检查。经典 EDIT 未响应 Ctrl+A，保留这一宿主差异，未更改映射。规范 ni3 编码从 canonical ID 和实验投影派生，不从生成词典反推。
- 零发送是测试替身注入；部分/未知结果用“发送一个真实 Unicode 前缀后返回错误”注入，并观察只留下该前缀、无自动重放。这些是故障路径开发证据，不是自然发生的 OS 错误或真人验收。
- Windows SendInput 不能原子绑定 HWND。提交前后检查和已观测焦点通知不能证明发送瞬间的所有竞态都被排除，发送计数也不等同于宿主接受。确认时切换应用可能产生结果不明；程序停止后要求人工核对，不声称任意宿主安全接受。
- 精确源码、检查、包身份和原始日志见 [P4 证据](../../../docs/testing/touch-keyboard/2026-10-20/p4/development-result.json)。P5 待记录完整独立中文包、最终源码、CI URL/哈希；P6 再恢复真实宿主、手指/笔、量尺和 ARM64 原生记录。未改动安装、默认输入法、用户数据或历史证据。
- PR #73 评审修复：自检整个生命周期的目标提供器固定为自有 EDIT 的窗口/焦点/进程/线程，所有恢复绑定都拒绝其他目标。英文主区 Enter 与侧 Enter 使用保留 Shift 的编辑事件；中文主区 Shift+Enter 仍确认候选，英文过期确认仍取消。新增相应回归，重测结果单独保存为 [review-fix 证据](../../../docs/testing/touch-keyboard/2026-10-20/p4/review-fix/development-result.json)，原 P4 记录保留。
