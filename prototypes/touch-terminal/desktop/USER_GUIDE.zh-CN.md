# 桌面触摸键盘使用帮助

2026-10-20 P4：开发以 **18u 主区**为准。中文受控预览和显式绑定目标后的宿主发送已接通，已完成自有临时 EDIT 检查。新包的 `Start Keyboard.cmd` 与 `Start Main Area.cmd` 仍共用 18u 英文入口；17u 与其 23u 全盘派生版本冻结为候选。完整中文包待 P5，手指/触控笔验收准备暂缓，不把开发检查当作实机结论。旧包的 `Start Keyboard.cmd` 仍为原全盘。

## P4 中文宿主输入：先绑定目标

此开发入口需完整检出目录和完整隔离词典；当前默认英文便携包尚不是 P5 中文交付。在仓库根目录运行：

```text
go -C go-backend run ./cmd/yime-touch-keyboard --root .. --numeric-zones none --remove-gutters --host-input --data-dir ../.generated/ascii-keyboard-134/data
```

1. 在目标应用的文本区亲自点好光标，再点键盘顶部“绑定目标”。绑定前不会发送。该按钮每次都会取消旧组合和触点，保留已进入目标应用的文字。
2. 组合栏只在键盘内显示。点候选或用空格/Enter 确认后发送 Unicode 文本；Esc 取消组合，不给目标发送 Escape。中文/英文、标点、数字和键帽仍使用原实验规则。
3. 没有活动中文组合时，编辑键及 Ctrl/Alt 快捷键发给目标。它们是否生效取决于应用：本轮经典 EDIT 未响应 Ctrl+A，但 Ctrl+Home、Shift+End 选择替换已通过。侧区仍旁路选词，Enter 作为宿主回车处理。英文主区与侧区的 Shift+Enter 保留 Shift，由应用决定换行行为；中文主区 Shift+Enter 仍确认首选候选。
4. 切换焦点（包括离开再返回）、隐藏键盘、打开帮助或显示环境变化后，组合与未完成触点取消。重新在文本区点光标并绑定，旧候选不会续发到新目标。
5. 若提示发送失败、部分发送或结果不明，先查看目标中实际留下的文字。程序停止后续发送，不自动补发、重放或删除前缀；核对后再明确绑定并重新输入所需内容。
6. Windows 不能将 SendInput 原子绑定到某个窗口。程序检查提交前后和已收到的焦点通知，但不能证明发送瞬间所有切换竞态都被排除；确认时不要切换应用。显示“输入事件已发送”不等于应用已接受，真实应用仍要各自验收。

本轮只验证自身临时 EDIT 及注入故障路径。手指、笔、Word/记事本、不同权限宿主及 ARM64 原生运行均不继承这个结果。程序不改变系统输入法选择，不访问用户词库，也不安装字体。

## 中文受控预览：只写窗口内文本

这是 P3 的源码开发入口，需要检出目录和完整隔离实验词典，当前英文便携包不包含这些资源。在仓库根目录执行：

```text
go -C go-backend run ./cmd/yime-touch-keyboard --root .. --numeric-zones none --remove-gutters --preview --data-dir ../.generated/ascii-keyboard-134/data
```

1. 等待完整词典校验和临时索引加载。顶部应显示“中文受控预览（不向其他应用输入）”，主区为 18u、342.90 mm。无需在其他应用放置光标。
2. 用变码/全码/简码按钮选择编码模式。按原盘面音元键输入，组合栏显示原始 ASCII，下一行显示当前页候选。点候选或空格/Enter 确认首选；主区 1–9 按实验规则选择当前页候选，有候选但序号缺失时不回退数字。主区 0 和非编码 ASCII 保持共用实验规则。
3. Esc 取消组合，不追加文本；退格先编辑当前中文组合。没有中文组合时，退格编辑“本地输出”。候选或键面按下后移出，即使返回也取消；候选已翻页或编码模式已换时，旧触点取消。重复抬手不会重复输出。
4. CN EN 同时切换输入语言与标点。切到英文会暂停并保留中文组合，切回中文仍可继续。中文始终显示 CN；英文时 Layout 切换原盘面/英文键帽，偏好在本次运行中保留。英文小写为基础层，Shift 为显式大写层；23 个空白键禁用，颜色和键位保持原样。
5. “标点入口”默认关，开启仅作用于已审阅的未标注标点入口；音元编码层仍是编码。六个已审阅 Unicode 符号键可直接输入。可选侧区的数字和 Enter 保留 literal 旁路，不选中文候选；两侧 Num Lock 独立，编辑态 5 无操作。
6. “字形 → ID”可恢复原 ID 标注；基础 60 音元显示来自实验解析文件，派生 R ID 仍显示 ID。字体只在当前进程使用，不安装到系统。
7. 本地文本支持按 Unicode 码点退格/删除、左右移动、全文 Home/End、Shift 选择、无组合时 Ctrl+A 全选；带侧区时可使用其编辑键。`│` 表示光标，`⟦…⟧` 表示选择。它不是完整文本编辑器，不支持宿主快捷键、剪贴板或文件保存。切换编码模式会取消未确认组合，保留已经确认的本地文本；“清空输出”清除组合和本地文本。
8. 关闭预览会丢弃内存文本。异常响应会断开预览会话且不重放；重新启动即可。词典或字形资源缺失时不回退到已安装产品。真实手指、触控笔、量尺及宿主应用结果仍需以后各自记录。

## 默认英文入口与网页样机

**默认独立桌面入口目前只支持英文跨应用输入。** 未带 `--preview` 或 `--host-input` 时，`Keys / Layout` 切换标准英文键面和原音元盘面；两者输出的都是英文/ASCII。灰色“中文未接入”表示此入口没有启用中文会话。原盘面上的音元 ID 是布局预览，不会生成汉字。

浏览器版本打开 <http://127.0.0.1:8766/>，可用 CN EN 切换中文/英文，中文候选选定后只写入网页正文。网页样机目前不能向记事本或 Word 输入中文。桌面中文宿主开发入口见上方 P4；独立完整中文包仍待 P5。

## 首次试用

1. 将新便携包完整解压到独立目录，保留 exe、配置目录与本说明在一起。双击 `Start Keyboard.cmd` 或 `Start Main Area.cmd`（18u 主区）；`Start Full Keyboard.cmd` 打开原大屏全盘。
2. 用尺子测量顶部 **100 mm** 线段。你已确认当前 27 英寸屏默认值与尺子一致，因此保持默认，不必点 Ruler。每 u 固定为 19.05 mm。
3. 在记事本或 Word 的正文中亲自点好光标，再触摸键盘。先输入 `abc`，点 Shift 再点 `a`，确认得到 `A`；再试退格、空格和回车。
4. 点一次 Shift 是下一键上档，也支持一指按 Shift、另一指点字符。Ctrl、Alt 可点一次再点字符；再次点同一个修饰键可取消。输入目标或焦点变化会取消未完成按键和修饰状态。
5. 左右 Num Lock 各自切换数字／编辑模式。数字模式直输数字；编辑模式用于方向、Home/End、PgUp/PgDn、Insert/Delete，5 不做任何操作。

## 盘面版本与 17u 的位置差异

| 启动文件 | 主区 / 盘面宽度 | 说明 |
|---|---|---|
| Start Keyboard.cmd | 18u 主区，342.90 mm | 新包默认入口，与主区入口共用配置 |
| Start Full Keyboard.cmd | 原全盘 24.75u，471.49 mm | 保留原大屏版本及中缝 |
| Start Main Area.cmd | 原主区去中缝 18u，342.90 mm | 当前开发基准 |
| Start 17u Main Area.cmd | 候选主区 17u，323.85 mm | 冻结保留；普通键保持至少 1u |
| Start 23u Keyboard.cmd | 候选主区加两侧共 23u，438.15 mm | 随 17u 冻结；去三条共同中缝 |
| Start Left Area.cmd / Start Right Area.cmd | 原主区加一侧，21u | 去中缝 |

新来源 `yime-cn-134k-23u-keyboard-layout.json` 含中缝的原始全宽为 23.75u；这里的 23u / 17u 均指去共同中缝后的净宽。为尽量保留 18u 的相对位置，采用用户稿仅有的两处音元跨行移动：N26 从数字／符号行移到下一行左端，N27 移到该行右端。其余音元保留原行与左右顺序。英文键面跟随原键身份移动，未臆造一套新英文映射。

17u 启动文件仍默认使用当前 27 英寸屏的像素换算。在另一台 16 英寸设备上，应填写它自己的有效显示宽度并重新量尺。例如在包目录终端运行：

```text
YimeTouchKeyboard.exe --root . --profile prototypes/touch-terminal/desktop/profiles/main-17u.json --screen-width-mm 实测显示宽度
```

显示宽度只量发光显示区，不含边框。15.6 / 16 英寸是对角线，不能代替宽度。实际键盘能否放下还取决于设备比例和可用工作区。

## 隐藏、移动和校准

- 拖动顶部标题栏移动键盘。Hide 隐藏；Ctrl+Alt+K 再次显示；Close 退出。该快捷键若被其他程序占用，状态栏会提示，暂时不要点 Hide。
- Help / 帮助显示简要操作说明；打开帮助会取消正在按下的键；关闭帮助后，请在目标正文重新点好光标。
- Ruler −1% / +1% 只修正像素到毫米的换算。已经准确时不要调整。校准只对本次运行有效；重启可用 `--ruler-observed-mm` 填写**默认校准下**100 mm 线段的实测长度。
- 换屏、旋转或更改显示设置后重新量尺。空间不足时程序会报错，不会自动缩小键帽。

## 常见现象

- `&` 可以直接写在 JSON 中。先前不显示是 Windows 把它当成快捷键前缀，现已按普通字符绘制，不需要写成 `&&`。
- 灰色空白键不发送内容。Caps Lock、系统键和 Pause 未接入；默认英文入口的中文开关未接入，P3/P4 的 CN EN 可切换语言。
- 按下后移出键面，即使再移回来也取消。不要同时按住真实物理键盘的 Shift/Ctrl/Alt/Win；程序不会擅自释放这些真实按键，会取消虚拟输入并提示。
- 某个应用不接收输入时，先重新点好正文光标，检查是否出现权限差异提示。尚不声称所有应用或管理员窗口兼容。

本版不安装输入法、不更改默认输入法或既有用户数据。真实触摸、触控笔、Word 与 ARM 原生运行仍需各自试用确认。
