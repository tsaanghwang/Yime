# 桌面触摸键盘中文操作指南

2026-10-20，P5 完整中文便携包。开发基准为 **18u 主区、100 键、342.90 mm**，每 u 为 19.05 mm。17u / 23u 保留为冻结候选。此前英文包的行为不追溯改变。

## 解压与启动

1. 选择与你的 Windows 架构匹配的包，完整解压到一个新目录。不要在 ZIP 内直接启动，也不要把不同包的文件混放。x64 已做受控开发检查；ARM64 目前仅交叉构建，尚无原生验收。
2. 双击 `Start Keyboard.cmd`、`Start Main Area.cmd` 或 `YimeTouchKeyboard.exe`，均默认打开 18u 中文键盘。无需源码目录、Go、Python、网络或另一个已安装输入法。首次加载需校验完整三模式词典并生成临时索引，请等待，避免重复启动。
3. 用实体尺复核顶部 100 mm 参考线。此前用户已确认当前 27 英寸屏默认值与尺子一致；其他设备仍要独立量尺。
4. 在目标应用正文中亲自点好光标，再点键盘“绑定目标”。组合只在键盘中显示，明确确认后才向目标发送。重新绑定取消旧组合和触点，保留宿主中已输入的文字。

`Start Preview.cmd` 打开只写窗口内文本的中文预览；关闭即丢弃内存文本。`Start English Only.cmd` 保留旧版英文输入路径，不启用中文引擎。实验结果不代表 Word、记事本、管理员窗口或所有应用均已接受输入。

## 中文组合与编辑

1. 用变码／全码／简码按钮选择编码模式。按原盘面音元键输入，组合栏显示原始 ASCII，下一行显示当前页候选。点候选或用空格／Enter 确认首选。切换编码模式取消未确认组合，保留已确认正文。
2. 主区 1–9 有候选时选择当前页对应序号；非空候选页上不存在的序号不操作，没有候选时才按既有规则输出数字。主区 0 和非编码 ASCII 保持实验规则。编码标点只在单字符组合时提供自身字面候选。
3. Esc 取消键盘组合，不向宿主发送 Escape。主区退格先编辑活动中文组合；无活动中文组合时编辑目标正文。
4. CN EN 同时切换输入语言与标点。英文输入暂停并保留中文组合，切回中文可继续。中文固定 CN 盘面；英文时 Layout 切换原盘面／英文键帽，保留本次运行中的偏好。英文字母基础层为小写，Shift 为显式大写。23 个英文空白键禁用，不按颜色推断功能。
5. 没有活动组合时，编辑键及 Ctrl/Alt 快捷键发给目标，是否生效取决于应用。经典 EDIT 的受控检查未响应 Ctrl+A，Ctrl+Home、Shift+End 选择替换已通过。英文主区和侧区 Shift+Enter 保留 Shift，由应用解释；中文主区 Shift+Enter 仍确认候选。
6. 左右数字区直接输入数字和 Enter，不选中文候选。两侧 Num Lock 独立切换数字／编辑模式，编辑模式 5 无操作。未标注主区标点入口开关默认关闭；开启不改变编码层。Unicode 符号输入仍限于六个已审阅键帽。
7. Shift 可点一次再点字符，也可一指按住 Shift、另一指点字符。Ctrl、Alt 可点一次再点下一键；再点同一修饰键取消。不要同时按住真实物理键盘的 Shift/Ctrl/Alt/Win；程序不会擅自释放这些物理按键。
8. 按下后移出键面，即使移回也取消。候选已翻页、模式已切换或目标已变化时，旧触点不继续提交；重复抬手不重复发送。

“字形 → ID”切回 ID 标注。基础 60 音元使用包内字体，派生 R ID 保持 ID 显示。字体只在本进程加载，不安装到系统。Caps Lock、系统键和 Pause 未接入。

## 失焦或发送失败

焦点离开（即使再返回）、隐藏键盘、打开帮助或显示环境变化后，未确认组合和触点取消。重新在目标文本区点光标并绑定后继续。

遇到发送失败、部分发送或结果不明，先查看正文中实际留下的内容。程序停止后续发送，不自动重放、补发或删除前缀。人工核对后重新绑定，再输入所需内容。

Windows SendInput 无法原子绑定某个窗口。提交前后检查和已经收到的焦点通知不能排除发送瞬间全部切换竞态；确认时不要切换应用。“输入事件已发送”不等于应用已接受。权限不同的宿主可能拒绝输入。

## 预览与包自检

预览中的“本地输出”支持按 Unicode 码点退格／删除、左右、全文 Home/End、Shift 选择和无组合时 Ctrl+A。`│` 表示光标，`⟦…⟧` 表示选择。它不是完整编辑器，不支持保存或剪贴板；“清空输出”只清除预览自己的组合和文本。

双击 `Check Package.cmd` 校验包内资源，并在内存中验证三模式选词，成功时生成 `package-check.json`。该检查不打开键盘窗口、不发送宿主输入；失败时不要把以前留下的报告当作本次通过。也可从终端运行：

```text
YimeTouchKeyboard.exe --check-package --data-report package-check.json
```

资源缺失、被修改或混包时程序拒绝启动，请重新完整解压同一包到新目录。不要手工改包内 profile、字体、指南或词典；资源清单与程序绑定。包内 manifest 及 CI 下载记录可用于核对身份，哈希不是数字签名。

完整词典每次启动生成独立临时索引，正常退出清理；强制终止可能留下本程序临时目录。程序不读取已安装产品或用户词库，不自动迁移学习数据。

## 盘面与显示

| 启动文件 | 盘面 | 输入入口 |
|---|---|---|
| Start Keyboard / Start Main Area | 18u 主区，342.90 mm | 中文，先绑定目标 |
| Start Full Keyboard | 原全盘 24.75u，471.49 mm | 中文，先绑定目标 |
| Start Left Area / Start Right Area | 主区加一侧，21u，400.05 mm | 中文，先绑定目标 |
| Start Preview | 18u 主区 | 仅窗口内中文预览 |
| Start English Only | 18u 主区 | 旧版英文路径 |
| Start 17u Main Area | 17u，323.85 mm | 冻结候选，旧版英文路径 |
| Start 23u Keyboard | 23u，438.15 mm | 冻结候选，旧版英文路径 |

上述名字均以 `.cmd` 结尾。保留的 17u 设计只有 N26/N27 跨行，其余音元保留原行和左右顺序；不继续独立开发或验收。没有实施“18u 缩短 1 毫米”，缩短参数仍待定义。

拖动顶部标题栏移动；Hide 隐藏，Ctrl+Alt+K 显示，Close 退出。快捷键被占用时状态栏会提示，暂时不要点 Hide。

Ruler −1% / +1% 只调整像素与毫米换算，不改变每 u 19.05 mm 的几何。校准只在本次运行有效。命令行可以填入有效显示宽度和默认校准下参考线实测长度，例如：

```text
YimeTouchKeyboard.exe --screen-width-mm 597.73 --ruler-observed-mm 98.5
```

显示宽度只量发光区，不含边框；屏幕对角线不能代替宽度。换屏、旋转或改变显示设置后重新量尺。空间不足时报错，不自动缩小键帽。

本包不安装输入法，不更改已安装或默认输入法、注册项、系统字体或既有用户数据。鼠标、模拟触摸、渲染图、内存检查和自有 EDIT 结果均为开发证据。真实手指、触控笔、真实应用及 ARM64 原生结果仍待分别记录。
