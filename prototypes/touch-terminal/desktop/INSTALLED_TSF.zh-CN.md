# 18u 安装版触控前端（test.13，v2 自动跟随）

test.13 沿用 test.11 引入的自动跟随及同源 v2 协议，并修复退出时私有字体路径缓冲区的生命周期。完整包的构建和离线验证不代表已经安装或通过真实宿主、物理触控验收；历史包实测保持原身份与结论。以下自动跟随说明要求完整匹配的 v2 包，不适用于旧版 v1 前端或 TIP，也不能通过单独替换前端升级旧包。

使用匹配的新完整包安装后，从 `%ProgramFiles%\YimeCore 18u Touch\frontend\Start Installed Touch Keyboard.cmd` 启动。首次加载需等待独立临时索引建立。前端验证安装维护清单中的 descriptor 哈希、完整载荷及编译绑定的界面资源；资源缺失、混包或身份不符时停止。test.6 没有这一入口，不能把新前端复制进旧安装目录。

test.9 安装版每次启动默认“适应屏幕”：保持18u键位与盘面比例，在启动时前台应用所在屏幕的工作区内尽量放大，靠底居中并避开任务栏。旋转、分辨率／DPI、任务栏工作区改变或拖到另一屏幕后重新适应；显示变化仍取消旧触点和宿主会话，显示稳定后自动发现当前正文，不恢复旧组合。设置中的“适应屏幕”可恢复该模式。命令行 `--window-sizing calibrated` 可显式使用实测尺寸；便携原型及冻结17u／23u入口的默认行为保持不变。

自动适应属于显示缩放，不是物理毫米校准；100 mm参考尺始终采用独立校准值。“填入实测 mm”或校准±1%会切换到本次运行的实测尺寸，超出工作区仍拒绝。重开安装版默认再次适应屏幕，不继承上次运行的实测校准或历史约99.5 mm结果。

在目标应用新建空白文档，选择独立18u输入法，再在正文放光标，等待前端显示已跟随当前正文；日常输入不需点绑定。不更改系统默认输入法。目标必须是原生 x64、与前端相同登录会话和权限级别；本候选不承诺 x86、ARM64、提权应用或不提供可写 TSF context 的控件。无法确认当前目标时保持不可输入并显示状态，不调用 SendInput 或剪贴板替代。

**实体键盘能力边界：本测试版专用 TIP 放行实体按键，只选择独立18u输入法后敲实体键盘会输入 ASCII。中文组码、候选与确认必须配合触屏前端。** `ni` 的实体键盘输入不能作为中文组合成功证据。

“设置 → 最近诊断”保留 test.8 的独立记录机制；本分支仅在自动连接状态改变时保存独立 JSON，相同目标的连续相同结果合并 到 `%LOCALAPPDATA%\Yime18uTouch\Diagnostics\binding-*.json`。详情列出时间、阶段、错误、顶层和正文焦点 HWND/PID/TID/窗口类及日志路径，不记录标题、正文、组码或候选。最小化和后续绑定不覆盖旧文件；本次运行可在界面翻页查看最近记录。保存失败会在详情中明确提示。打开诊断、帮助或设置时暂停自动发现；关闭后重新发现当前正文，绝不恢复旧触点或自动输入。

`endpoint-not-found` 表示指定正文线程端点不存在，需结合是否激活专用 profile 判断，不能单凭这一项认定未选择输入法；`endpoint-access-denied`/`endpoint-busy` 分别表示管道打开权限/占用问题。`peer-*` 为前端身份、登录或权限校验失败；`no-focused-document`/`no-top-context` 表示宿主未提供对应 TSF 对象；`focus-*`/`foreground-changed`/`context-changed` 表示绑定期间目标身份变化。管道断开或超时仅登记传输失败，不能猜测具体根因。提交结果未知时先核对正文，禁止自动补发。

校准可以选择“设置 → 填入实测 mm”，用内置数字键盘填入**当前标注 100 mm 的线实测长度**，再点“一次校准”。例如初值实测58 mm，填58；比例乘100/58。可输入小数、删除、清空或取消；超出工作区时拒绝并保留原比例，不自动缩键。缩放保持原窗口中心，靠近屏幕边缘时夹紧到工作区。现有已认可比例不需重新调整；2026-11-04 的约99.5 mm认可记录保留，不通过修改本机当前运行状态重新校准。

前端复用现有三模式 YimeCore/keyboardlab 引擎、CN/EN、候选、翻页、标点和触点规则；规范字典与标准版分离，没有第二套编码算法。组码和候选留在键盘窗口；确认文本经当前宿主的专用 TIP 写入。旧 Broker 自有宿主检查入口保留，不会与前端共享会话或用户数据。

普通文字、侧区字面输入和候选确认通过 TSF 替换当前选区。退格、Delete、左右移动、Home/End、全选及 Shift 选区也通过 TSF；左右与删除按 Unicode 字符边界处理。**Home/End 定义为文档首尾，Enter 插入 CRLF，Tab 插入制表符**，不是系统导航键，不保证宿主表单提交或控件跳转。Ctrl+A 映射为全选；其它 Ctrl/Alt、功能键及不支持的修饰组合返回提示，不向系统合成快捷键。

正文修改只有在实际 `DoEditSession` 完成后才确认。普通失焦、上下文变化、最小化或显示变化撤销旧会话、取消未确认组合，恢复后自动连接全新会话。只读状态查询失败不视为文字已发送。

编辑超时、拒写或回执不可信时保持“需要核对”锁定；切换应用、最小化恢复和自动连接都不能解除。先查看正文，再点“核对后继续”，此后只接受新输入；旧请求、候选及触点永不重放、补发或回滚。“重连”只用于手动重新发现或核对后的恢复，不是日常输入步骤。

前端通过 v2 管道按正文 PID/TID 发现目标，由 TIP 核对活动专用 profile、线程焦点、文档和 context；状态查询与编辑串行，每个已完成动作在接受前确认原目标身份。状态检查期间仍处理窗口取消和最小化消息。版本不匹配时拒绝连接，不把新前端复制进旧安装。设计、安全合同及源码验证见[自动跟随开发说明](../../../docs/project/18u-self-developed-integration/AUTO_FOCUS_FRONTEND.zh-CN.md)。

`Start Local Preview.cmd` 仅在键盘窗口内预览，不能作为安装版普通应用通过的证据。第一次实际使用先用实体尺校准；不继承其它机器或旧包的毫米参数。手指、每支笔、姿态、模式和宿主分别记录。候选包、自动回归和隔离原生测试均不代表 Word/Edge 或物理验收通过。

`Check Package.cmd` 仅检查资源和三模式内存选词，报告保存到当前用户临时目录，窗口显示具体路径；不写 Program Files，不向应用输入。结束后将报告另存到该批次证据目录。

正常退出只关闭前端与连接、删除本次临时索引，不卸载输入法，不改默认选择，也不迁移用户数据。维护前先正常退出前端并保存、关闭使用该输入法的文档；包升级使用原 installer/simple 正常维护流程，保留原包和证据。
