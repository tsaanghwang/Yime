# 默认动态组句词库

Yime for Windows 默认运行 `yime_core_trial` 方案。该方案包含 1,124,631 条已经通过正式拼音和音元
编码链路的单字及预组合部件，并启用 Rime 动态造句、整句学习和用户词频。

## 运行边界

- 安装包只携带 `yime_core_trial.dict.yaml`、对应 schema 和 manifest。
- `yime_full`、`yime_variable`、`yime_shorthand` 的大容量字典不进入安装包，也不作为默认或回退
  运行词库。
- 旧大词库仍保留在开发仓库和原型统一来源库中，只用于离线数据真源、候选筛选和回归测试。
- 反查和系统词库扫描在旧变长词典不存在时，使用默认核心词典；这不会生成或猜测新编码。

## “噪声”如何处理

Yime 不声称原始语料没有噪声。统一来源库会保留词、专名、术语、句法片段、偶然相邻字串及其
来源证据；完整保留是为了可追溯，而不是宣布它们都值得成为运行候选。

发布边界位于运行词库：

1. 只有通过来源、拼音、规范音节、音元编码和布局门禁的条目才能进入核心词库；
2. 没有预装的完整长词不再被视为“未编码”，而是由已编码单字和预组合部件动态生成；
3. 旧大词库不能作为安装包回退项，防止遗留用户副本重新被反查或审计工具优先读取；
4. 开发期发现的高频新词先进入晋升报告，必须审核后才可成为公共候选；
5. 用户误选造成的个人排序噪声由用户学习、屏蔽和可恢复的数据重置处理，不反写系统真源。

因此，“来源库含噪声”和“默认候选受噪声污染”是两个不同命题。当前架构允许前者存在并受审计，
同时用发布门禁阻断后者。

## 验收证据

- 固定生产范围回放：冷启动首选 2,440/2,449（99.6325%），95% Wilson 下界 99.3030%。
- 开发者人工复核：2,449/2,449 可输入。
- 加速用户学习漂移：3 个随机种子、18 个虚拟用户、30 个虚拟日、共 540,000 次事件，全部验收项
  通过；重复输入首选率均高于 99.97%。
- 纯净用户态人工闭环：5/5 个严格冷启动压力句均可构造；3 个需要纠正的长句在一次纠正后全部成为
  首选，重启后 3/3 保持；未预装的“逼尿肌反射亢进”由已编码部件动态组成并直接首选。

这些数字是产前回放和加速模拟结果，不替代未来真实用户遥测。开发期发现的高频缺词通过
`lexicon-promotion-scan.exe` 进入候选晋升审核，不直接污染系统词库。
