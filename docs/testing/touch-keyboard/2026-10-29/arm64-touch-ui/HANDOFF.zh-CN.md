# ARM64 新触屏盘面测试交付

本任务接收新版18u触屏试用盘面。先在ARM64机器独立验证预览，再进入真实宿主；不需要等待PR合并。已固定[PR #82成功CI的完整ARM64包](CI_DELIVERY.zh-CN.md)，下载、哈希和原生架构须先核对；使用[接续任务文字](TASK_PROMPT.zh-CN.md)及已填包身份但结果全待测的模板。

## 范围和入口

- 完整解压ARM64包到新的独立目录，先运行`Check Package.cmd`并保留新生成的`package-check.json`。
- 使用`Start Touch Screen Preview.cmd`：98键（84主体＋14大控制），F1–F12移出常驻盘面，设置及帮助在控制行。普通`Start Preview.cmd`仍为历史100键视图。
- 默认深灰、较大键面字及可选按键音；本入口启用按键音。防回弹试验保持0，纯笔/手指分别观察。
- 不复制微星16英寸机器的58.8校准参数或97mm实测值。先记录本机原始显示尺寸、缩放及实际测量，再按本机情况调校。
- 完整包包含独立实验词典与私有字体，不安装输入法、不改变默认输入法、系统字体、声音设备或用户数据；本任务不使用任何安装器。

当前x64参考结果为宏碁笔主体336项、既定预览控制37项，均属于本地c35包；手指结果分包保存，微星CN148及重复触点问题保留。这些结果帮助选择回归重点，不填入ARM64通过项。此次CI版本还包含默认关闭的笔防回弹试验代码，不能把它视为已获物理验收。

## 第一轮：ARM64 基础测试

按顺序执行，鼠标、实际手指、笔的结果分栏保存；没有相应硬件时写“未测/无设备”，不要用鼠标或模拟输入补齐物理结果。先做短组，异常即记录具体步骤和实际结果，不追求速度或用力敲击。

| ID | 操作 | 检查点 |
|---|---|---|
| A00 | 记录机器、Windows版本、原生ARM64、屏幕分辨率/缩放、触控及笔型号、屏幕姿态 | 记录实际环境；不沿用其他机器的环境结论 |
| A01 | 核对固定下载ZIP与exe SHA-256；完整解压，运行Check Package | 当前包资源校验和三模式内存中文检查通过；此项不代表物理输入 |
| A02 | 打开Start Touch Screen Preview | 显示新98键盘面、上下档字符完整、CN/EN文字随状态变化；记录裁切、遮挡和宿主可用空间 |
| A03 | EN依次输入abc；清空后Shift再点a；分别使用实际手指和可用笔 | 得abc及A，Shift一次性消费；不漏字、不把鼠标通过写成手指/笔通过 |
| A04 | CN设置内依次选变码、全码、简码；用ID键帽输入N08/M03、N08/M03/M03/M03、N08/M03，分别点候选“你” | 原组合ni/niii/ni，明确点选后只输出“你”；清空后再测另一模式。候选不符时保留现场，不猜键 |

| A06 | CN清空输入1234、左箭头两次、开启选区、Home、数字9；独立重新准备后用End代替Home | 分别选中12/34，替换后934/129，组合为空；后续再按37项预览控制清单展开 |

A03–A07按方法分别记录。缺设备不阻断其他可测部分，但未测项保留。重复输入应记录键、状态、触点方式及可复现步骤；不据此直接归因于功率、驱动或笔灵敏度。

## 第二轮与真实宿主

基础轮通过后，继续补齐ARM侧主体四层、候选序号/分页与上下文、设置选项、并发触点等独立用例。单笔与手指混合输入须明确标为混合场景。

真实应用使用`Start Touch Screen Keyboard.cmd`，只在新建空白且不保存的测试文档内操作：先放置光标、再点“绑定”，检查输入位置、盘面遮挡、正文可见性和宿主按钮可操作性。失焦、最小化、帮助或发送异常后重新核对正文再绑定。不在本轮安装或切换已安装输入法；Word/Edge分别记录，不能用预览或受控EDIT替代。ARM原生运行、触控、笔和宿主均以本机实际结果为准。

## 回报与合并门槛

复制`RESULT_TEMPLATE.json`到本机包外证据目录，填入固定包身份、环境及各项实际结果，附包检查报告和必要截图。保留原始失败，复测另记；不记录既有私人文档内容。

PR合并前至少完成：CI通过、代码审阅、A01/A02原生资源/启动检查，以及具备硬件条件的触控、声音、帮助和生命周期基础观察；没有设备的部分须明确标为未测，由审阅者结合范围决定，不虚构全验收。候选专项与真实宿主继续分阶段推进。当前安排不授权自动合并。
