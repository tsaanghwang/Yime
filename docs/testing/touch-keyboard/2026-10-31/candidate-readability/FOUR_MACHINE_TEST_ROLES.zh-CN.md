- 跨平台对比只围绕明确问题安排，并固定包源/版本、操作与观察标准。每个显示屏使用自身校准与实测记录；同一支笔换屏也不能继承旧屏通过。记录实际输入设备、屏幕、原生/仿真架构及证据层次；模拟输入、自动开发检查和真人结果分别报告。
