# ARM64 触屏可读性原始证据归档

此目录保存本机包外开发记录及各轮完整包的清单副本，原始来源为：

`C:\dev\Yime-deliveries\touch-candidate-readability-20261031`

## 目录与完整性

- `v1/` 对应原交付根目录的 `records/` 与 `arm64/manifest.json`；`v2/` 至 `v7/` 对应原目录下同名轮次。
- 每轮 `records/` 中的全部 `.json`、`.log` 均按原始字节复制，包括失败日志、空日志及 `RESULTS.before-*.json` 历史快照；每轮另保存实际名为 `manifest.json` 的包清单。
- 共125个原始文件，合计164,595 bytes，其中118个包外记录、7个包清单。此数目与大小不包含本说明、索引和属性文件。
- [INDEX.json](INDEX.json) 为每个原始文件记录来源绝对路径、归档相对路径、字节数与SHA-256。归档时逐项重新读取来源与副本，验证原始字节、长度及哈希一致。
- 原始文件内容、编码、换行及字段均未改写；`sourceChanges`、源码HEAD、运行参数、失败状态与历史下一步描述保留原样。文件名中的 `v1` 等后缀可能表示该轮检查的尝试次数，实际交付轮次以外层 `v1/` 至 `v7/` 为准。
- 本目录的 `.gitattributes` 对所有文件设置 `-text`，禁止Git换行转换，保留索引所记录的原始字节。
- 目录中不包含程序EXE、字典/data负载、runtime-state、运行时词典索引、真实宿主正文或包外临时运行目录；这里只保存记录及清单。

## 结果边界

这些文件是本机ARM64开发检查、包检查、预览准备和用户反馈的原始证据归档，不是新的CI产物或新的验收结论。旧轮次、PR #82或其他机器的通过项不继承到新包；失败日志不因后续通过而删除，也不改写为通过。各清单中的 `hardwareAcceptance` / `arm64NativeAcceptance` 等字段保持构建时原值，应与包外原生执行记录分别阅读。

v5及v6用户反馈按原记录保留，不能扩展为全键、纯手指、纯触控笔或所有宿主通过。归档时，v7候选框的真人观察与实际选择结果仍待用户反馈；其自动回归和包检查通过不替代人眼或手指/笔验收。新CI包、x64/MyComputer结果以及后续真人结果应另立记录，不覆写这里的历史副本。

## 记录内容与公开范围

原记录包含开发所需的Windows绝对路径及其中的本机用户名、机器/屏幕名称、时间、PID/HWND、源码提交和包哈希，以及本轮界面反馈原话。内容核查未发现凭据、访问令牌或真实宿主文档正文。内存包自检中的“你”、空预览正文及为候选预览准备的编码属于受控开发检查记录，不作为真人输入验收。为保持可核验性，这些已有元数据没有脱敏或重写。
