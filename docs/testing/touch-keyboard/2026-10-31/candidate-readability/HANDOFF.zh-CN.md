1. 预览/组合栏及候选字号随校准尺寸计算，与普通键文字同档；保留长候选备用字号。字体创建失败时回滚，不能留下半更新的比例与字体。
2. 触屏盘面为 `touch-screen-v2`，横18u、纵5.7u、102个位置：84个原主体键与18个等宽控制键。控制键及左右翻页键均宽1u、高0.8u，与当前主体普通键匹配。
3. 控制行依次为设置、帮助、绑定/清空、取消、CN/EN、←、→、Home、End、选区、全选、退格、Delete、空闲1、空闲2、空闲3、最小化、退出。新增退格仅编辑已确认正文；有中文组合或英文暂停组合时拒绝操作，主体 Back Space 的组合编辑行为保持。空闲键不执行动作、不发音、不改变选区或绑定。
4. 主体键、两侧L形键、18个控制键和两个翻页键统一立体外观。字符键文字内收、可见间隙增加，仍保留原完整点击范围；L形键没有内部接缝，文字位于下方宽处。
5. 候选框立体，序号与候选内容按完整多行文字块上下左右居中。深灰主题保持清晰白字，文字不加阴影。当前有效候选才显示按下效果；移出立即重绘，旧页、取消或暂停后的旧触点不提交。

这批改动包含控制行退格、空闲键与移出重绘等行为，不应仅按颜色或字号改动审查。

## MyComputer 接续顺序

1. 只读核对本 PR 与 main 的差异及本交接。保留原工作区和未提交改动，使用独立工作树；如果主线后来前进，先比较具体差异，再在同一交付分支上整合，不另起相互竞争的盘面改版。
2. 待本 PR 的固定 CI 交付记录公布后，按其不可变 run/artifact ID 下载完整 **amd64** 包，核对ZIP、exe、manifest、PE架构、资源哈希与 `sourceCommit`。源码 checkout 不是包交付。本机 ASUS 使用同一轮的 **arm64** 包，两台结果分别记录。
3. 将包解压到新的独立目录；结果、截图、运行状态放在包外。保留旧包。先运行随包自检，再用 `Start Touch Screen Preview.cmd` 打开新版，量尺校准，核对18控制键、翻页尺寸、文字/字形完整性及候选多行居中。
4. 新版优先做小批回归：候选按住/移出取消/换页旧触点失效；中文组合与EN暂停时工具栏退格保护；已确认正文退格与三个空闲键；最小化恢复与无声退出。手指、笔、鼠标分别登记，自动检查不得代填真人结果。
5. 预览确认后，再在用户主动准备的空白测试文档中检查 Word/Edge 绑定、候选与提交一致、编辑及恢复。记录实际应用、输入方式和包身份，不改变默认输入法，不安装输入法，不修改既有用户正文。
