## 校准修复

旧 GUI 默认按 597.73 mm 屏宽计算像素比例。用户的原始参考尺读数应一次性修正为 `100 / 57.5`，不与旧校准复合。按该读数算得键区宽 3832 px；原来两侧固定 10 px 外留白使总宽 3852 px 超过屏宽。

新实现仅收紧触屏窗口外留白至可容纳的范围；当前算例为左右各 4 px、总宽 3840 px。18u、19.05 mm/u 键距、编码与 Windows 250% 缩放不变。若键区本身超屏仍拒绝，不自动缩小。
