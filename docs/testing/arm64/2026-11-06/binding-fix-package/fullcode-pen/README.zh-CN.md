## 真人笔最小用例

当前记事本第四个标签页已恢复为空白；先前“你12呢”保留在第三个标签页。真人步骤中的正文定位、设置、绑定、编码和候选点选均要求使用同一触控笔：

1. 点空白正文，确认当前输入法为“音元拼音·18u触摸”。
2. 在键盘“设置”选择“全码”，返回键盘；中文、无 Shift。
3. 再点正文，然后点“绑定”；报错则停下并保留错误。
4. 点 `N08/n` 一次，再点 `M03/i` 三次，每次抬笔后再点。检查组合 `niii` 与候选“你”。
5. 用笔点“你”；正文应只有一个“你”，组合清空。

此用例同时补真实已安装宿主中的固定全码和一次笔输入，范围不扩展到全部笔/并发触点矩阵。既知自动化点击键盘会改变前台焦点，故真人操作期间不使用自动化点击代替笔，不重复其失败绑定路径。
