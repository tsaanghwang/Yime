# 这次请运行桌面的安装入口

桌面入口名称：**安装 18u ARM64 .5 修复包**。

它打开的是安装检查窗口，会马上显示中文进度并保存日志。触摸键盘可能随登录自动出现；键盘弹出不表示安装已经开始或成功。

1. 保存现有文档。把当前输入临时切换到已有的系统英语输入项，不更改默认输入法。
2. 正常退出相关应用和 Codex，然后从 Windows **开始 → 电源 → 重启** 正常重启。
3. 登录后先运行桌面的 **安装 18u ARM64 .5 修复包**，暂时不要重开 Codex、记事本或选择 18u。
4. 入口会立即显示“已经启动”，接着检查完整包和文件占用，不需要先按键。如果仍有占用，会列出应用名称，保存日志后停止；这时安装没有启动，18u 后台也没有被停止。不要结束 Explorer/System 或强行替换文件，保留结果回到对话核对。
5. 无占用时才进入标准安装器，按正常 Windows 提示继续。入口不会自动重试；看到安装器返回后，保留窗口显示和日志。
6. 回到本次 Codex 对话，核对实际安装版本、文件和进程，再测试新的空白记事本标签中的绑定和中文正文提交。安装器返回成功还不等于输入复测通过。

若桌面入口不可见，可双击本目录的 **开始安装18u修复版.cmd**。请普通双击，不要使用“以管理员身份运行”；安装器会自行显示正常 Windows 提示。

日志保存在本目录：`18u-entry-start.log` 表示桌面入口已打开，`18u-start-日期-编号.log` 和同名 JSON 记录每一步及是否真正启动安装。真正进入安装后，另有 `native-install.log` 和用户目录下的 `Yime Setup Logs`。

这只是本机安装入口和说明的改进。原 `.5` 完整 ZIP、1156 个文件的 `package` 目录、旧入口和旧证据均保持原样；不会重置用户数据或修改默认输入法。
