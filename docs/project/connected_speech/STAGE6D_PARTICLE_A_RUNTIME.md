# 阶段 6D：筛查后语气词“啊”全量双轨运行实现

阶段 6D 先用 30 条人工样本验证六类条件读音和三模式投影，随后按项目负责人的全量授权，把通过
来源与位置筛查的显式 `啊/a5` 全部接入运行词典。它仍不是跨词、跨候选的能产规则：程序只处理
规范核心词典中已经存在的候选和音节位置，不增删汉字，不改规范拼音，并永久保留未音变 `a5` 码。

## 准入范围

- 词尾 `啊/a5`：候选内部有明确前接音节，全部按前一音节末音归入六类；
- 句中 `啊/a5`：只准即时重叠 `X啊X`；当前保留 29 个候选；
- 42 个无法回溯 BCC、万象原始上下文的非重叠三字截片：候选整体进入系统排除表，不生成音变码；
- 词首或独立“啊”：没有可确定的前接末音，保持规范路径；
- 非 `a5` 的“啊”：保持来源读音，不强制改作语气词条件读音；
- 同一候选有多个合格位置时逐位置处理，例如“啊啊啊”保留第一个词首“啊”，处理后两个位置。

机器范围保存在 `particle_a_stage6d_runtime_scope.tsv`。任何后来出现的非 `X啊X` 句中记录如果尚未
进入排除表，生成器会失败，要求先完成来源复核，不能静默类推。

## 当前物化结果

- 系统排除：42 个候选；
- 放行：6,679 个显式候选、6,680 个可音变位置；
- 含句中 `X啊X`：29 个；含词尾“啊”：6,651 个，两组在“啊啊啊”处有一个交集；
- 六类出现次数：`PA-U` 1,207、`PA-N` 1,374、`PA-NG` 1,061、`PA-APICAL-FRONT` 179、
  `PA-RETROFLEX` 320、`PA-VOWEL-IY` 2,539；
- `PA-NG` 的 1,061 个候选因 N26/N12 共用物理键，条件读音成立但无需制造重复码；
- 其余 5,618 个候选在变长、等长、省键各物化 5,618 行，共 16,854 行；
- 所有新增行初始权重固定为 `1`，由用户学习再提升；
- 规范 `a5` 路径和候选文字完全保留。

## 完整性门禁

生成器每次从三模式核心、基础码表、音节分解、布局、六类规则、全量运行范围和 42 条排除表重新
推导，检查：排除表全部命中、句中准入恰为 29 个 `X啊X`、六类齐全、所有音变位置均已投影、
三模式均不增码、规范候选权重与路线仍存在、输入文件只读、输出哈希一致。构建、打包和已安装运行
验证同时要求三份词典、清单和系统排除表齐全。

真实 librime 回归同时验证句末“样子啊”和句中“走啊走”的音变码、未音变码在三种模式中均能输入
同一候选。Go 候选响应回归验证 42 条排除项不可见，且当整个候选桶均被排除时空格/回车不能误选
后端候选。

## 回退

移除主句子词典中的 `yime_particle_a_stage6d_<mode>` 导入即可一次撤销全部条件读音别名，不需要
改动核心词典、基础码、规范拼音或用户数据。系统排除表是独立来源门禁，不随音变别名回退而自动
撤销。
