# 阶段 6B：语气词“啊”离线三模式投影

阶段 6B 在阶段 6A 六类末音审计的基础上，验证“前接末音类别 → 目标首音 ID → 三模式编码”的
中间链路，仍不生成或接入运行时候选。

六类目标一律从规范 `a5` 复制后三个乐音位置，只把首位虚首音分别替换为
`N24 / N08 / N26 / N27 / N19 / N23`。其中 `wa5 / ya5` 表示把 `'` 换成 `w / y`，
不复用规范独立音节 `wa5 / ya5` 中另带呼音的四音元，也不增加位置。舌尖前类语流读音统一记作
`ɹa5`：`ɹ` 是 IPA 式的派生首音记号，不是规范拼音声母 `z[ts]`；它使用 N27，不与 N13 混同。

程序为核心词典中每条显式“啊/a5”记录生成三模式试算，报告码长变化、既有同文路径和预测重码桶。
任一模式比规范路径更长的记录必须标为 `blocked_surface_longer`。全部记录继续保持
`research_only`、`runtime_eligible=false`，候选文字保持“啊”，不自动改成“呀、哇、哪”。
任何后续运行实现都只能添加并行低权重音变别名，既有未音变 `a5` 三模式路径必须原样保留。

运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\audit-stage6b-particle-a.ps1
```

输出位于 `.tmp/particle-a-stage6b-projection/`。后续若要建立运行时试点，必须另行提供显式构式来源
复核清单，决定增码路线是否继续阻断，并添加三方案真实 Rime 与安装态宿主门禁；本阶段报告不能直接
作为运行词典输入。

当前实算得到 6,657 条显式记录、19,971 行三模式投影，全部保持四个位置且只替换首音，增码和
未决均为 0；预测 84 个模式映射进入多候选桶。N26 与 N12 受控共用 `'`，所以 1,057 条
`PA-NG` 在三模式中已有同文同码路径，但报告仍保留 N26 语义。任何后续增码都会被视为实现错误并
由测试拦截。全部数字只描述离线试算，运行时别名仍为 0。

首批小规模复核已由[阶段 6C 人工复核门禁](STAGE6C_PARTICLE_A_REVIEW_GATE.md)承接；阶段 6B 的
全量清单继续只是机器母表，不能整体批准。
