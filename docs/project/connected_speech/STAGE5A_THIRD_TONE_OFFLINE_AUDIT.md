# 阶段 5A：上声变调离线范围与三模式试算

> 状态：首轮离线审计完成；运行时别名为零

## 1. 本轮目的

阶段 4 的显式词汇化儿化编码输入暂告结束后，阶段 5 先处理上声变调。能产儿化仍缺少经过授权、
能明确区分独立 `ér`、儿缀、融合儿化和口语提示的词表，本轮不再扩大儿化范围。

首轮只盘点核心词典中恰好两个音节、两个规范调类均为上声的直接条目。暂按首音节表层读作阳平建立
`3 3 → 2 3` 离线假设，但直接词典条目只提供词条边界候选，不自动证明它构成唯一韵律域。因此所有
结果仍为 `research_only`，不得写入三模式运行词典。

三音节以上条目中出现的局部双上声，以及三个或更多连续上声，统一要求显式韵律分组并保持
`deferred`；不得以相邻两音节为窗口递归改写。

机器可读范围见 [third_tone_sandhi_scope.tsv](third_tone_sandhi_scope.tsv)。

## 2. 派生链

```text
两音节直接词典条目
    → 由等长码反查同调类规范音节及稳定四音元
    → 首音节乐音音质不变，调级从“低—低—低”替换为“低—中—高”
    → 布局键位投影
    → 同时派生等长、变长、省键
    → 码长、既有路径、候选桶、权重和只读门禁
```

若某一节质在规范音节清单中没有实际出现的二声音节，例如 `bing2`、`jing2`，审计器仍从上声音元的
稳定音质组派生低—中—高序列，并把“规范清单未收录该二声音节”记录为证据状态。它不向规范音节表
添加音节，也不把条件调值冒充规范读音。

## 3. 首轮完整库结果

对 1,166,300 条核心词典记录的只读审计得到：

- 两音节双上声候选 11,020 条，全部能够从稳定音元派生三模式编码；
- 其中 2,102 条的表层二声音节没有出现在当前规范音节清单中，但音元派生完整；
- 三模式共试算 33,060 条映射；所有规范权重均能在三模式中一致读回；
- 7,201 条候选在至少一种模式中比规范路径更长，按现行总门禁阻断；
- 其余 3,819 条只表示“码长未增加”，并未因而取得运行资格；
- 7,896 条模式映射预计进入已有或新增的多候选桶；
- 三模式中均已存在同文本表层路径的候选为 0；
- 长词中含相邻双上声的记录 49,675 条，其中含三个以上连续上声的记录 5,575 条，全部暂缓；
- 未决投影 0；运行时别名 0；规范输入文件前后哈希一致。

## 4. 门禁结论

本轮证明了上声调级替换和三模式投影在工程上可以确定完成，但没有证明 11,020 条词典记录都应接受
同一表层读法。下一批不能直接物化全量别名，应先建立带来源的高频双音节复核子集，至少核对：

1. 词条是否构成一个明确韵律域；
2. 是否存在重读、并列、停顿或其它阻断条件；
3. 表层读法是否为强制、常见可选或仅特定语境可见；
4. 任一模式增码的记录是否继续按总门禁排除；
5. 新旧候选桶中的排序影响是否可以接受；
6. 与“一、不”、轻声及儿缀/融合儿化相交时，是否已有显式冲突裁决。

只有这个人工审定子集完成后，才可另立阶段 5B 临时 Rime 小词典试验；阶段 5A 本身不授权运行接入。
