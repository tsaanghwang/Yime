# 语流音变准备与分阶段实现包

本目录保存《普通话语流音变的编码输入实现》的准备材料、离线试验和经单独门禁批准的小规模运行
实现。规范拼音、基础码表、候选文字和用户数据仍不可由语流模块改写；未经显式来源授权的记录不得
进入运行词典。

## 决策

准备阶段 P 的第一批实施对象“阶段 0：离线数据格式、校验器和报告器”已于 2026-08-09 完成，
没有实现任何运行时输入别名。阶段 0 只读取人工维护的审定记录，在临时目录产生报告；所有模块
默认关闭，所有
`research_only`、`deferred` 和 `rejected` 记录的运行输出数量必须为零。

阶段 1 既有轻声链审计以及阶段 2A/2B“一、不”既有链路盘点、离线试算和临时 Rime 回退也已完成。
阶段 3-0 已完成轻声四种语境调值、全词典三模式竞争审计和去重复核队列；阶段 3-1 已用 10 条分层
样本通过真实 Rime 三模式输入、排序和整批回退。全部类别仍为 `research_only`。两条“一、不”试验
读音及轻声投影报告都只存在于 `.tmp`；报告中的正式运行别名生成数为零。

阶段 3-3 已建立第一版“统一语境调层—质层假设模型”：把韵律域、上声、“一、不”、轻声、儿化、
虚首音、“啊”、音节边界同化/异化、音质弱化与时域延展和三模式投影组成有界、非递归的偏序规则图，并用
独立冲突表记录当前无法由语言事实唯一裁决的交叠。它是可证伪、可替换的离线工程模型，不是语言学
定论，也没有接入运行时候选。

阶段 4 已开始词汇化儿化的小规模显式试点：131 条来源记录现均具有明确的“基础音元 +
卷舌/鼻化特征”改写规则，形成“儿缀兼容 + 融合儿化”双路线能力。65 条从三模式核心、66 条从 PSC
外围层取得候选归属与来源权重；实机排序审计后，全部新增别名改用固定初始权重 `1`，由用户学习
再作提升。融合附加词典因而每模式 196 条、合计 588 行；131 条均进入融合反查旁表，
融合编码待决数为 0。该试点禁止后缀类推、禁止改变候选文字，也不批准能产儿化。阶段 4A 又把
编码不再从儿化表层 IPA 或表层分类归纳；只允许按“基础音元元组 → 逐位置特征改写 → 派生儿化
音元 ID → 三模式编码”生成。派生儿化音元与物理键位拆开：中央卷舌音元继续复用 3 个共享键位类；`a˞`、`ɤ˞`、`ã˞`、`ɤ̃˞`、
`u˞` 的三调派生音元依次试用 `F/D/S`、`R/E/W`、`Y/T/Q`、`V/C/X`、`P/A/Z` Shift 层专用键。

阶段 4 的显式词汇化儿化编码输入现暂告结束。阶段 5A 已开始上声变调的只读离线审计：核心词典中
11,020 条两音节双上声候选均能从稳定音元派生三模式编码，其中 7,201 条因至少一种模式增码而阻断；
长词中的局部双上声和三上声链全部暂缓。该阶段没有生成运行时别名，能产儿化也没有开放。
阶段 5B-0 又从三模式均不增码且表层音节已见于规范清单的记录中选出 24 条高频复核项，建立来源、
快照漂移、权重和三模式投影门禁。项目负责人已核准它们在没有其它内部韵律约束的通常语境中采用
`2+3`；词条之间的列举停顿不构成阻断。核准 24、待复核 0。阶段 5C 已以固定初始权重 `1` 接入
这 24 条三模式别名，同时保留规范未变调码，并支持连续组句。

另有 315 条经复核、但原核心未收录的 PSC 轻声和儿化读法，现以固定权重 `1` 的三模式独立外围层
补入候选（轻声 183、儿化 132）。这项变更只补充可输入读法，不裁决主要读音、不改核心排序，也不
批准轻声表层调值或能产儿化规则。

稳定兼容路径和可选语流路径继续分层：

- 轻声 `5` 和儿缀 `er5` 是始终保留的兼容表示；
- 表层轻声、融合儿化和语气词同化只能作为有来源、可删除的并行实现；
- 语气词“啊”阶段 6A 只审计显式 `啊/a5` 词条的六类前接末音，保持候选原字且不生成运行时别名；
- 阶段 6B 把六类分别投影到既有 `wa5/na5/ya5` 或 N26/N27/N19 派生首音，离线计算三模式码长与碰撞，运行时别名仍为零；
- 原始来源观察不可变，转录校正和工程判决分开保存；
- 同一规范候选的三种输入模式必须由同一四音元记录确定性派生。

## 版本策略

- `schema_version`：记录结构不兼容时递增整数；版本 1 在阶段 0 内冻结。
- `ruleset_version`：规则语义采用 `MAJOR.MINOR.PATCH`；新增兼容规则递增 MINOR，修正文案或来源定位
  递增 PATCH，改变既有规则含义递增 MAJOR。
- `record_revision`：单条工程判决的递增整数；不得覆盖其所引用的原始来源观察。
- 清单必须记录 schema、ruleset、布局、模式转换、规范词典和输入源 SHA-256。

## 准备阶段评审结论

第一批只建立离线基础设施，因此没有批准融合儿化韵、轻声具体表层调值或 `[ŋ]`、`[z]`、卷舌类
派生首音。后来阶段 4 只对“至少一个汉字 + 词尾儿”、且有 PSC 儿化来源授权的显式词条另行批准了
小规模双路线试点；这项批准不能反推到阶段 0 的其他 `research_only` 或 `deferred` 记录。

阶段 0 门禁通过只表示离线基础设施完成；当前运行时包含上述显式词汇化儿化试点、不改变核心排序
的 PSC 规范来源低频外围候选，以及 24 条逐条核准的上声变调低频别名。PSC 层保存有来源的轻声/
儿化候选读法，不意味着轻声表层调值、能产儿化、语气词或其他语流音变已经接入运行时。
