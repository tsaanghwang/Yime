# 阶段 6A：语气词“啊”离线末音分类审计

阶段 6A 只建立可复算的离线范围、校验器和报告器，不生成或接入运行时候选。

审计对象限定为核心规范词典中：候选文字明确以“啊”结尾，且末音节由规范码表解码为 `a5` 的既有词语记录。程序读取前一音节在物化音节分解表中的规范韵母，按固定优先级归入六类：`u`、`n`、`ng`、舌尖前元音、舌尖后元音或 `er`、其余元音尾。

本阶段坚持以下边界：

- 候选文字始终保持原样，不自动把“啊”替换为“呀、哇、哪”；
- 六类范围全部为 `research_only`、`runtime_eligible=false`；
- `[ŋ]`、`[z]` 和卷舌类派生首音没有正式音元 ID 前，不做三模式投影；
- 不建立跨词边界的全局相邻音节类推；
- 输入词典、规范码表和音节分解表在审计前后的 SHA-256 必须一致；
- 报告必须完整列出已分类记录、六类计数和未决项，运行时别名计数必须为零。

运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\audit-stage6a-particle-a.ps1
```

输出位于 `.tmp/particle-a-stage6a-audit/`。只有在六类边界、派生首音 ID、布局投影、显式构式来源和碰撞报告分别通过复核后，才能另立阶段 6B；阶段 6A 本身不能成为运行时生成器。
