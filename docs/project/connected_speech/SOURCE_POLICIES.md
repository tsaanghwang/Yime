# 语流音变来源解释政策

## 总规则

来源层只回答“原始材料写了什么”，工程判决层才回答“Yime 如何解释和输入”。每条观察必须保存
稳定来源 ID、原始词形、原始注音、文件哈希及页码、条号或其他定位。OCR 或人工校正写入独立字段，
不得替换原始字符串。

任何来源都不能单独决定候选频率、规范主读、轻声深层本调和儿化输入策略。相同词形的冲突观察允许
并存；只有工程判决记录可以批准兼容路径或表层路径。

## 来源目录

| policy_id | 来源 | 可以证明 | 不能据此证明 | 无调与儿尾处理 |
|---|---|---|---|---|
| `pypinyin_phrase_v1` | pypinyin 词语数据 | 该来源提供某一词语读法 | 规范主读、实际频率、所有儿尾形式一致 | 原样保留；无调须经来源制度判断，`r/er/ér` 不自动互换 |
| `wanxiang_phrase_v1` | 万象词库 | 该来源提供某一词语及拼式 | 仅作参考、规范主读或语流事实 | 原样保留；不得因为末尾写 `er` 就自动判为 `er5` |
| `bcc_text_v1` | BCC 字串和上下文 | 词形、上下文、出现频率 | 未标注的读音、轻声、儿化或变调 | 只有显式注音记录才进入读音观察；纯文本不反推拼音 |
| `psc_annotated_v1` | PSC 词表、儿化表、轻声表和朗读材料 | 特定测试材料出现的词形—注音对 | 主读排序、词典义项完整性、文字未写“儿”时应自动补字 | OCR 校正独立保存；口语 `r` 提示与正字法词形不一致时暂缓 |
| `pronunciation_review_v1` | 普通话异读词审音表 | 审音条文明确规定的适用范围 | 未被条文覆盖的频率、词义或语流变体 | 波浪号、括号、“除……外”和举例符号先恢复条文结构再解释 |
| `project_manual_v1` | 项目人工审定 | 对已有来源观察作工程判决 | 新造语言事实 | 必须记录审定人、日期、理由和所引用的观察 ID |

## 来源优先级

本目录不定义“一份来源恒为首选”。决策顺序是：

1. 先判断来源是否真的覆盖该词形、义项和语境；
2. 再判断转录是否可靠、符号制度是否明确；
3. 规范条文只在自身适用范围内裁决；
4. 多来源一致可降低复核优先级，但不能删除任何原始观察；
5. 冲突、儿尾结构不清或文字—注音不一致时使用 `deferred` 或 `research_only`。

## 版权和仓库存放

外部 PDF、DOC、XLSX、OCR 页面和完整来源数据库不进入 Yime 仓库。仓库只保存：

- 导入、校验和复核程序；
- 来源政策、文件哈希和定位信息；
- 项目自行形成的判决记录和少量回归样例；
- 不足以替代原作品的错误差异、统计和工程报告。

本规则不代替法律意见；取得授权后仍应保留来源层与工程判决层的分离。
