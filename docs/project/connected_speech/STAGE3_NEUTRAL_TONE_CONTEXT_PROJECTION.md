# 阶段 3-0：轻声四种语境调值离线投影

## 目的与边界

本阶段先验证“轻声语音事实层—三调级音元投影层”的接口，不处理轻声是不是主读，不回填深层本调，
也不改写现行数字调 `5` 和三个中调乐音组成的兼容编码。

首轮暂定四种语境类别：

| 前一音节已经实现的表层调类 | 轻声五度值 | 三调级投影 |
|---|---:|---|
| 阴平 | 2 | 低调 |
| 阳平 | 3 | 低调 |
| 上声 | 4 | 中调 |
| 去声 | 1 | 低调 |

条件必须读取前一音节完成其它变调后的表层调类，不能跳过“一、不”等先行规则直接读取词典本调。
四种类别和五度值保存在语境事实层；三调级投影只负责产生稳定音元 ID，不得反向覆盖事实层。

## 全词典展开结果

837 次是音节级投影与同节质三声的碰撞观察数，不能直接理解为在完整候选库中只新增 837 条记录。
把同一规则展开到现有轻声词条后，离线审计得到：

- 轻声去重记录：101,928；可取得前接调类并完成投影：96,855；因缺少有效前接调类而暂不适用：5,073；
- 暂不适用项中，1,705 条是单字或词首轻声读法，没有词内前驱；3,368 条是连续轻声，当前规则不能用
  第一个轻声的规范调号冒充其表层调值来支配第二个轻声；两类都继续保留兼容 `*5` 路径；
- 与现行兼容编码相同：20,415；会改变输入码：76,440；
- 三模式试算记录：290,565；其中既有映射 61,245，不会造成新的候选或排序变化；
- 真正新增的三模式映射：229,320；进入已有候选桶：3,729，占新增映射约 1.63%；
- 有竞争的新增词条：1,243，占可投影记录约 1.28%；三种模式的词条集合和结果完全一致；
- 每种模式各有 595 条按现有权重会成为桶首，13 条与桶首并列，635 条低于已有桶首；其余 75,197 个变化词条没有既有竞争者；
- 例如“学生”的新表层码会与低频“学省”进入同一候选桶，但读取原有权重后仍由“学生”居首；这属于可度量的有限重码，不等同于整体候选结构被破坏；
- 2,309 条记录在完整词条任一位置含有“一、不、七、八”等先行调值规则对象，不能在未完成规则排序前直接批准；
- 竞争词条与先行规则依赖项合并去重后形成 3,532 条复核队列；其中 2,309 条优先处理先行规则依赖，
  其余按并列桶首、升为桶首、低于桶首分级；
- 阻断问题：0；运行时别名：0；所有被审计输入文件前后哈希一致。

排序影响只统计 `mapping_status=new` 的映射。`already_present` 即使所在桶含有其它候选，也标作
`already_present_no_change`，不得虚增“新增后会改变排序”的数量。

工程判决 `neutral_surface_homophone_v1` 已确认：已审表层读音相同造成的重码进入同一候选列，不作为
生成失败；各候选继续使用自己的规范词条权重。当前 1,243 个竞争词条因此记为“已接受的候选竞争”，
但只有其表层规则通过 `reviewed_surface_rule` 门禁后才能生成别名。该判决不放行 2,309 条先行规则依赖、
3,368 条连续轻声或 1,705 条无词内前驱记录。

## 首轮暴露的问题

1. “四种调值”在键盘层并不是四套独立编码；`1、2、3` 按现有音元定义必然进入同一个低调桶。
2. 上声后的轻声表层投影与现行 `*5` 完全相同，因此该类别不会增加新的音元路径。
3. 三个低调类别大多与同节质三声发生重码。前一音节仍保存语境条件，但它不能消除“同一完整编码
   同时可解释为轻声表层读法或三声规范读法”的候选竞争；必须在完整词组层继续统计实际竞争候选和排序。
4. 72 次低调投影没有同节质三声规范音节，说明“投影元组有效”不等于“现有规范拼音表中一定有对应三声音节”。
5. 当前原型把轻声音节三个乐音位置都投影到同一调级；这只是保持四音元位置不变的首轮工程假设，仍需用实例验证。
6. 连续轻声需要单独定义链式条件；在此之前不得把前一个轻声机械还原为规范调号，也不得把 3,368 条记录
   混入普通“前接一至四声”的投影。
