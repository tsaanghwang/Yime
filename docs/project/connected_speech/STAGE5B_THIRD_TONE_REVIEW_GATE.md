# 阶段 5B-0：上声变调高频复核门禁

> 状态：24 条通常语境读法已由项目负责人核准；已进入阶段 5C 低频运行别名

阶段 5A 的 11,020 条双上声候选中，只有 3,819 条满足三种模式均不增码。阶段 5B-0 再从中取
24 条高频、表层二声音节已见于规范音节清单的直接双音节词条，建立人工复核入口。机器清单仍
保存预选时状态；项目负责人的持久化判决另存于
[人工判决表](third_tone_stage5b_decisions.tsv)，不覆盖机器观察。

一般规则背景引用两项规范转载材料；它们说明变调与规范拼音标调的关系，却不逐条裁决词语。因此
项目负责人现已核准：这 24 个常用词在没有其它内部韵律约束的通常语境中允许
`3+3 → 2+3`。词条之间的列举停顿不切断词内韵律域，仍可读作 `2+3`；只有发生在词内两音节
边界上的停顿、内部强调、内部并列或其它内部韵律约束才作为阻断条件。核准采用双路径兼容政策：
规范未变调码保持原样，变调码只作为输入同一候选的附加别名。机器文件分别为：

- [高频复核清单](third_tone_stage5b_review.tsv)；
- [人工判决表](third_tone_stage5b_decisions.tsv)；
- [一般规则来源](third_tone_stage5b_sources.tsv)。

复核门禁会重新运行阶段 5A，从当前核心三模式词典取回候选、权重、编码、桶规模和码长，再与
受版本控制的复核快照核对。它只向 `.tmp/third-tone-stage5b-review/` 写报告，并强制：

1. 每个复核项仍能唯一对应阶段 5A 候选；
2. 表层音节已在规范音节清单出现；
3. 三种模式均不比规范路径长；
4. 三模式规范权重一致；
5. 每条机器预选恰有一条人工判决，适用范围和内部阻断条件完整；
6. 每条判决都要求 `parallel_alias_keep_canonical`，不得用变调路径替换规范路径；
7. 不生成运行时别名，不写 PIME、Rime 用户目录或正式词典。

运行命令：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\audit-stage5b-third-tone-review.ps1
```

审计结果为：核准 24、待复核 0、当前阶段 5A 匹配 24、三模式投影 72、未决 0、运行时别名 0。
阶段 5C 已把这 24 条迁入单独、可删除的三模式低频运行层；具体策略和真实 Rime 门禁见
[阶段 5C 说明](STAGE5C_THIRD_TONE_RUNTIME.md)。本文件及阶段 5B 工具仍只负责复核，不直接生成运行别名。
