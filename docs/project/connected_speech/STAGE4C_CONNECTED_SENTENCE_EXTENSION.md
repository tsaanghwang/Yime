# 阶段 4C：儿化与 PSC 外围词的连续组句扩展

## 问题

阶段 4 的融合儿化码和 PSC 低频外围词原先分别由独立 `table_translator` 提供。该结构适合整词精确
命中，但覆盖词典关闭了 `enable_sentence`，连续码中也没有保存音节分隔。因此融合码能够单独输入
“大婶儿”或“打转儿”，却不能继续组成“大婶儿打转儿”或“大婶儿工作”。

## 实现

运行数据现在为三种输入模式各生成三层 script 词典：

1. `yime_psc_peripheral_sentence_<mode>.dict.yaml`：保存 315 条 PSC 外围记录及明确音节边界；
2. `yime_erhua_mixed_sentence_<mode>.dict.yaml`：只保存 131 条经授权融合儿化路线及明确音节边界；
3. `yime_sentence_<mode>.dict.yaml`：通过 `import_tables` 合并核心词典和上述两个扩展层；阶段 5C
   后来又以独立导入项加入 24 条已核准上声变调别名。

主 `script_translator` 改用第三层。原有精确覆盖词典仍保留，规范词典、候选文字、规范拼音、基础音节
码和核心权重均不改写。融合儿化仍只覆盖原来 131 条显式授权词，不产生后缀类推。

融合词的音节边界从现有稳定音元 ID 序列重新投影，不从键码长度猜测。儿化附着音节在融合路线中只
占一个音节；此前的完整词语音节保持原边界。PSC 外围词则直接使用三模式生成器已有的 `*Spelling`
字段。

## 范围说明

- 核心词典已有的词汇固有轻声本来就能参加连续组句；
- 本阶段补齐的是 PSC 低频外围轻声/儿化记录和显式融合儿化路线；
- 阶段 3 的语境轻声表层码仍为研究产物，没有接入运行时；
- 阶段 4C 本身不接入上声变调；其后阶段 5C 已将 24 条逐项核准记录作为独立低频层导入同一
  句子词典，删除该导入项即可单独回退。

## 回归

真实 librime 在变长、等长、省键三种模式下必须同时通过：

- 融合儿化整词仍可输入；
- `大婶儿打转儿` 可由两个融合儿化词连续组成；
- `大婶儿工作` 可由融合儿化词与核心词连续组成；
- `石头滚动` 可由核心词汇固有轻声词与核心词连续组成；
- `商量工作` 可由 PSC 低频轻声词与核心词连续组成；
- PSC 外围 sentence 词典每模式 315 条，融合儿化 sentence 词典每模式 131 条；
- 删除 sentence 扩展层后，核心词典和原精确覆盖层仍可独立恢复。
