# 双独立产品开发计划

2026-09-14 更新：安装维护采用 [简版入口](../../installer/simple/README.md)，取代原复杂事务与恢复矩阵。

YimeCore 为主要开发线，Rime/PIME 独立稳定维护。支持只选任一套或选择两套，各自完整运行，不要求同步版本或自动退役另一套。

两套隔离产品身份、运行端点、安装目录、私有字体、设置、学习和用户词库。安装、卸载、重装只作用于所选产品；不能依赖另一套已安装文件或自动迁移另一套数据。可共享规范源数据及离线生成工具，生成资产分别随包携带。

安装器提供单套与双套选择。两套操作先检查全部选定包，再逐套执行，失败停止并报告，不实施跨产品回滚。默认保留本产品用户数据；显式重置只处理本产品状态。生产数据迁移及备份恢复后续另行安排。

开发端完成构建、制包、自动检查和原生卸载重装与输入验收，再推送；对应 CI 成功后，由测试端下载安装完整包，执行最终独立环境验收。故障由开发端修复重新交付，测试端不承担安装脚本开发。

维护验收覆盖单装两种产品、两个安装顺序、分别卸载并确认另一套输入、装回、一次选择安装和卸载两套，以及重启后输入。源码/隔离测试与用户实机验收分开记录。当前通用包支持 x64 Windows 和 WOW64 应用；ARM64 保持独立源码实验，不以交叉编译声称安装可用。

本机两套卸载重装及重启前后输入已由用户确认；测试端单套、双套和交叉维护已有成功记录，实测条件及未测项见 [验证记录](../../installer/simple/VALIDATION.md)。详见 [当前交接](../../installer/simple/HANDOFF.md)。

说明、报告和必要测试数据通过 [Git 分支交接](../../installer/simple/HANDOFF.md)，不再依赖共享目录。
