# 独立 18u x64 单次闭环开发包

这是开发验证包，不是安装器、日用输入法或旧残留恢复工具。实现基线为 `e3962604d333df098f31ad689e11801c8b1622c5`；实际打包源码提交以 `manifest.json.sourceCommit` 为准，不冒称新增打包提交仍为 e396。本包没有运行真实注册闭环，不能继承标准版、PR87 预览版或其他包的验收。

## 先停在核验／准备

本次制包授权不等于本机执行授权。不要双击 EXE、自动提权、关闭安全保护、运行旧注册／恢复命令；不要覆盖旧目录或复制本机 MSVC 缓存当交付。先保存开发侧给出的 ZIP SHA256 和 manifest SHA256，用已有工具核对 ZIP；解压到新的独立目录，原 ZIP 保留。

依赖：原生 Windows x64，已有 Python 3.12 或更新版本。Python 使用标准库，不需 pip。未安装 Python 或安全保护阻止时停报，不自动安装或绕过。5 个 PE 文件的实际 Authenticode 状态见 `signatures.json`；哈希一致不等于可信签名。

获准进行静态准备后，可执行以下模板（不是本轮自动执行指令）：

```text
python prepare_activated_loop_package.py --package <新包绝对目录> --manifest-sha256 <开发侧独立提供的64位哈希> --output <包外全新绝对目录>
```

默认 `prepare` 只核完整文件集合、全部 SHA256／大小、PE 架构及类型、独立产品和布局／词典身份，生成包外 `development-manifest.json` 与 `entry-result.json`。不启动任何 EXE、不注册、不读写语言配置。它仅把固定资源映射为本机绝对路径；本地生成清单哈希不代替原包 manifest 来源锚。文件集合包含 19 个载荷及 manifest 自身，不能混入校准、日志、旧包或其他文件。

## 三种模式不能自动串联

- `prepare`：默认静态核验和路径准备，输出目录必须新建且包外。
- `--mode preflight`：必须另外获准；固定 Stage1 的一次默认只读预检，经 Windows Job 有界采集到新证据目录。它不注册、不自动提权；`prerequisitesSatisfied=false` 如实报告，不自动重复或转注册。
- `--mode register`：必须另外明确批准管理员单次注册／编辑／正常撤销，且提供准备清单及独立哈希、精确确认串。入口只调用原受保护编排器，不裸跑 EXE，不自动执行预检后再注册，不重试，不提供 recover 模式。

真实执行前仍重新核 MyComputer 主机、原生 x64、当前线程 HKL 与 TSF `0804`、提升状态、独立身份缺席、直接测试模式缺席及固定 DLL 身份。持有包不构成这些条件已满足。不要改默认输入法、语言、其他产品或删除预存身份来让预检通过。

## 真实运行与异常边界

已授权单次注册时，写入仅原 v3 受保护事务范围：独立 COM、中文 profile、键盘类别及当前用户启用记录；正常结束撤销本次创建项。正文限自有宿主单次候选选择，并要求实际提交回执、独立读回、一次 select 请求、撤销后旧 provider 失效、独立缺席核验同时成立，不是 Word/Edge 或全量物理验收。

控制器 180 秒、外层 Job 240 秒；独立只读核验 30 秒。超时／未知／错误停止，保存所有证据。停止进程不等于撤销成功。不要重跑注册、复用证据目录、删除账本或清理未知残留。DPAPI 密文账本位于注册证据目录的 `controller/registration-ledger.dpapi`，不要把密文贴聊天；仅汇报摘要及哈希。异常恢复必须另行审阅和授权，不使用 a05 明文账本入口或旧 v2 包猜测处理。

正常清理成功与旧 provider 失效分别记录；`editAttempts` 是真实 select 派发次数，不是内部编辑回调次数。未查询的返回码保持 null，未采集退出码不写成 0。失败结果不能用“日志为空”或截图替代。

## 文件与证据

`bin/` 为固定 5 个 EXE/DLL及两个 Python helper；`source/` 为 4 份固定布局／产品／音节源；`data/` 为资源锁指定的完整三词典及索引清单，不是小样本词库。根目录含受保护编排器、包入口、此说明、签名记录和 manifest。注册／只读证据始终放包外，包不可修改。

报告只需提供实际源码 SHA、ZIP/manifest 哈希、模式、退出／超时／进程树状态和对应结果摘要；不声称未执行的模式通过。CI 日志受仓库清理策略影响，下载包与独立哈希应自行妥善保留。
