# 18u ARM64 暂存文件身份与句柄绑定设计（未实现）

状态：仅源码设计和离线合同。基线 `e7a1baabed684ed5477c1ae81372de7e8e486e12` 的暂存候选按独立核准记录比较文件路径、大小及 SHA-256，但 `Assert-Arm64ProtectedStageBoundary` 没有文件 ID 或持续打开的句柄。相同字节的新文件可通过哈希检查。`Setup.ps1` 的 ARM64 安装／卸载拒绝门保持关闭；本文不授权真实维护。

## 最小实现边界

复用现有包清单、独立核准记录、受保护暂存和安装器。未来的受信任维护入口增加一个短生命周期的原生 ARM64 句柄租约；不改字典、输入运行时或 x64 路由。租约逻辑必须来自独立核准、预置于管理员保护位置的入口或模块，不能从待核准包加载。核准记录的逐文件 SHA-256 是**内容来源约束**；暂存后记录的卷序列号及 128 位文件 ID 是**本次文件对象约束**，不能互相替代。文件 ID 不是发行者身份，也不能单独证明 ACL 安全。

1. 在管理员保护目录创建全新暂存后，从暂存的每个文件句柄计算 SHA-256，按独立核准记录核对完整清单、大小及内容；同时取得每个文件和目录的 `FILE_ID_INFO`（卷序列号、文件 ID），形成本次不可由包提供者编辑的暂存封印。文件 ID 不写回包清单或用户可写目录。任一查询失败、ID 不可用或文件系统不受支持即拒绝。
2. 使用前在固定本地 NTFS 路径上逐级打开目录句柄（目录需 `FILE_FLAG_BACKUP_SEMANTICS`），对最终成员使用 `FILE_FLAG_OPEN_REPARSE_POINT` 并拒绝重解析属性。逐级比较暂存封印的目录 ID、文件 ID、最终句柄路径及受保护 ACL；路径别名、额外成员或缺少成员均拒绝。打开每个已核准文件时只请求读取，分享模式仅允许读取，**不分享写入或删除**；有不兼容的既有句柄则停止。对同一打开句柄重新计算哈希，再与独立核准和封印比较。
3. 入口从取得所有句柄开始，持续持有目录及文件句柄，直至受控维护进程退出并完成结果、进程 SID／管理员／原生 ARM64 身份和暂存内容复核。若将来由 PowerShell 7 按路径读取 `Setup.ps1`／`Product.psm1`，入口仍须验证它实际打开的是被封印的对象；文件句柄不能自动转交给 `-File` 或 `Import-Module`。注册器、DLL 和其他会影响执行的文件也必须处于同一租约。当前 `Setup.ps1` 的拒绝门不得因租约模型测试通过而移除。
4. 任一校验、打开、共享、身份、进程退出码或复核失败，停止后续维护并保留现场，不回退到用户可写来源或 x64 仿真。实际产品变更前必须另行证明入口、系统原生 PS7、环境与模块搜索路径的可信性，并补齐设置页卸载入口。

## Windows 仍存在的窗口

- 路径检查与取得第一个句柄之间、逐级取得目录句柄之间仍有竞争。封印 ID 与最终路径复核用于拒绝已切换对象；真正按父句柄相对打开后代或等效的原生入口设计、硬链接及挂载点处理仍需实现与实测。`FILE_FLAG_OPEN_REPARSE_POINT` 不能替代对所有祖先的检查。
- 持有只分享读取的句柄能阻止通常需要重新打开文件的写入、删除和重命名，但它不能证明 PowerShell 之后按路径重开时一定使用该句柄。既存可写映射、管理员／SYSTEM、内核组件、权限或挂载状态变化及解释器的其他加载路径仍是独立边界。执行后检查只能发现问题，不能撤销已经完成的注册或文件变更。
- 仅持有句柄并比较文件 ID 仍不足以放行按路径执行。若无法证明解释器和注册工具在租约期间实际加载的是这些已核验对象，就继续保持拒绝门关闭；不得把执行后的哈希复核当作执行前的保护。
- 因此，租约从取得到释放的寿命、脚本／模块／注册工具实际加载对象、目录链稳定性和 ACL 继承必须在可丢弃原生 Windows ARM64 虚拟机验证。若 VM 不可用，ASUS 的隔离 NTFS 目录、额外账户和任何权限操作须另行审阅与批准。

## 离线测试与真实验证分界

`tools/yimecore/test_arm64_stage_handle_design.py` 仅用临时普通文件的打开描述符、设备号和文件索引模拟文件身份：同字节替换、异字节替换和原地改写必须被身份／哈希比较拒绝，未替换文件通过。它不调用 `FILE_ID_INFO`，不持有 Windows 跨进程保护句柄，不创建链接、账户或真实 ACL；测试通过不表示上述 Windows 窗口已封闭。

真实 NTFS／不同账户待验证：目录和文件的 `FILE_ID_INFO` 与卷序列号；逐级路径重解析、junction／符号链接和硬链接；父目录及继承的删除子项与写入 ACE；普通账户检查后替换、既存可写句柄或映射、共享冲突；PS7 `-File`、模块导入、注册器及 DLL 的实际加载对象；同一用户和另一管理员账户、真实 UAC／设置页卸载、用户数据保留。此列表均不是本阶段的通过项。
