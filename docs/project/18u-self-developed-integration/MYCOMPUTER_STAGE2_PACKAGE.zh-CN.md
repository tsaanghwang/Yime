# MyComputer 独立注册激活开发包（阶段 2）

本包不是完整输入法交付，不包含完整输入主流程验收；也不继承 PR87 预览包、其他机器或旧安装包的验收。
包不包含 Broker、词典或触摸前端；独立 18u 的注册激活切片不要求启动标准版 Broker，
这不是已打通 Broker 编辑或完整输入链的证据。PE 的 AMD64 标记只证明编译目标，不证明在任何机器原生运行。
当前仅供开发侧构建、检查与审阅，**尚未授权在用户电脑运行，尤其不能注册或恢复注册记录**。

## 固定内容与身份

包内仅含 `YimeTextService18u.dll`、`YimeMyComputerActivationStage1.exe`、
`collect_mycomputer_preflight.py`、`windows_job_once.py`、本说明及 `manifest.json`。
manifest 记录准确源码提交、每个载荷的字节数和 SHA-256、两 PE 的 AMD64 架构及 Windows
`Get-AuthenticodeSignature` 实际查询状态。`NotSigned` 就是未签名；文件哈希不能代替可信发布者签名。
签名状态仅针对查询时的字节，不表示安全性或当前机器已接受其信任链。

包外 `package-evidence.json` 给出 ZIP 与 manifest 的 SHA-256。校验时应从可信交付渠道取得固定值，
不能只信任 ZIP 内可一起被替换的清单。ZIP 哈希不等于解压文件或其他重组 ZIP 的哈希。

## 运行边界（不是本轮执行指令）

工具无参数默认只读预检，不会创建注册日志、注册、启用或激活本产品。
独立预检采集器仅允许固定包内工具的只读入口，先核清单及全部文件哈希，使用受限子进程运行并保留
原始输出和退出状态。它依赖 Python 及包内 `windows_job_once.py`；不安装 Python 或任何系统组件。
采集器同样不因随包提供而获得用户机执行授权。具体参数、固定哈希及后续步骤须在独立授权后交付。

注册入口与恢复入口明确分离，不自动从预检升级到注册、不重试、不自动执行恢复。
已有 18u 身份、错误设备/架构、未知前置状态或不匹配的 DLL/日志均应停止。
本包不调整默认输入法、系统语言或其他产品；不支持 ARM/x86 安装验收。

即便后续获准注册，工具的 `activation-unconfirmed`/退出码 4 也不是激活成功：
还需该次真实 DLL 激活标记、清理结果和独立只读缺席验证，经离线证据门核对。
证据一致性不认证日志来源，不证明完整宿主输入，也不能替代未来固定包下的可信采集。
