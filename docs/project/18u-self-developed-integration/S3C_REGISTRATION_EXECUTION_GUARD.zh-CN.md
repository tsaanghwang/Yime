# S3c：一次注册执行保护（本地开发审阅稿）

基于已发布 `2e2ba5e81c4f9083ac25e0972c3d9ae89a2769d7` 的注册／激活切片；本批仅获准开发、非注册测试与审阅，**未发布、未触发 CI、未在任何系统注册或操作 MyComputer**。原 v1 包、原始预检和已有验收记录保持不变。

## 目标与非目标

补齐一次显式注册的受限执行、同次证据以及异常后的独立恢复衔接，不扩成安装器，不证明完整输入、Broker 编辑、触摸前端或 Word／Edge 接入。默认只读预检不自动升级为注册。开发授权、文件下载、预检条件满足都不是管理员写入授权。

原预检公式仅为八项条件的 AND；提升进程必须再次实际检查主机、原生架构、两项语言、权限、本身份缺席、DLL 哈希及无测试旁路。不得通过改语言、跳过检查、禁用其他 TIP 或修改默认输入法来取得通过。

## 单次执行链

1. 独立固定 manifest 哈希核验新 v2 包及完整载荷。新包保持独立身份，增加专用编排和离线证据检查文件；不能把它们随意塞进原 v1 包或沿用原 ZIP 哈希。
2. 显式注册确认后，只在新的包外事务目录建立请求与证据。Job 先创建挂起进程并取得真实 PID／创建时间，将其与固定源码、manifest、EXE／DLL 哈希持久化成功后才允许执行。失败不启动，不重试。
3. 只执行固定原生注册入口。原生入口在写入前再次检查条件，使用新的 DPAPI 账本；每项可能写入之前先保存归属／尝试状态。账本不是普通可编辑 JSON。自身新 COM 根的固定归属标记绑定本轮 PID／创建时间；新账本版本拒绝旧无标记记录，防止把后续同 GUID／同 DLL 注册误认成本轮。
4. 正常完成仅在整个子树结束、原生返回 `activation-unconfirmed`／4、同次实际 DLL 激活标记、原生撤销结果和独立只读缺席核验全部一致时，报告本次注册／激活／撤销证据成立。API 成功或 exit 0 本身不是 DLL 激活证明。
5. 超时、异常、输出缺失、结果不明或残留均停止并保留原始证据；不自动重放注册，不自动恢复。超时终止子树不等于注册未写入或已撤销。

## 恢复是另一项显式操作

恢复必须另有明确许可和新的证据目录，保留原请求／结果。只读恢复检查先核原进程 PID／创建时间、DPAPI 主机与账户绑定、DLL 身份、账本顺序与自身注册范围；实际恢复入口还要再次核同一账本密文哈希及全部归属门，不能只信任先前检查。

只有可证明原执行子树已结束，且原生原 owner 状态、账本和当前自身记录全部可判定时，才允许一次限定恢复。单次恢复声明防止同一原事务被两个编排并发恢复；已尝试或有未知状态不能自行再次恢复。不得删除预存项目、其他产品或无法证明属于本次的残留。恢复须同时匹配当前 COM 根的本轮标记；仅剩 TIP 残留而世代标记缺失时停止。其他自身记录撤销失败或残留未知时保留 COM 标记，不为清空残留先删掉归属证据。

若编排本身中断而最终子树状态缺失、账本损坏／缺失、PID 状态不可查询或当前注册内容发生变化，**保守停止，不承诺自动恢复所有崩溃状态**。需要另行审查证据，不能按 GUID 猜测清理。恢复保持原账本密文和历史标志不变，以新的恢复回执和独立缺席核验记录结果。恢复通过也不能补造此前激活成功。

## 验证与交付边界

- 本地测试覆盖生产编排的成功／失败／超时／未知／拒绝恢复和证据合同；模拟不等于 Windows DPAPI 或真实注册清理验证。
- 现有 Windows 非注册 CI 曾验证主机门拒绝，不证明更深层 DPAPI 恢复；本批未增加实际注册运行。
- 账本的 DPAPI 绑定与哈希不是对同一账户恶意篡改的完整安全隔离。固定包仍需记录真实签名状态；不得关闭安全机制运行未签名文件。
- Windows 的 TSF 路由可能初始化已有 TIP；本工具不是隔离沙盒，不改变其注册／默认设置。
- 发布、Windows 非注册验证及新 v2 包交付须按后续批准范围执行；MyComputer 一次管理员注册及条件恢复的许可仍独立确认。本文不提供本机执行命令。

## 本地审阅结果

本批 90 项 Python 测试通过（包含既有 30 项回归），4 组实际共用 C++ policy 在严格警告与 UBSan 下通过；独立审阅已覆盖世代归属修复。Windows API 源码仅静态审阅，本批尚无 MSVC 或 Windows 注册／恢复执行结果。已有七项未注册正式链失败不改记通过。
