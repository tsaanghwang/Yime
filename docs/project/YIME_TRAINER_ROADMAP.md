# Yime 练习子项目路线图

## 1. 定位与当前基线

练习器的目标不是做一个通用英文打字软件，而是帮助使用者建立以下完整联想：

> 标准拼音音节 → 首音／干音结构 → 四个音元 → 当前物理键位 → 连续字词和短句输入

当前第一阶段已经具备五类练习：音元练习、分段练习、编码练习、字词练习和
短句练习；能够读取当前导入布局、1729 个正式编码音节和三种输入方案；字词与
短句可以从只读系统运行库抽题。下一阶段的重点不是继续堆叠题型或美化界面，
而是补齐“发现错误—解释错误—安排复习—迁移到真实输入”的教学闭环。

## 2. 下一阶段必做事项

以下五项均为练习器进入完整试用阶段前的硬门槛，按实施顺序排列。

### 2.1 题目无歧义与抽题质量门禁

- 字词和短句必须记录本次抽中的正式音节码序列，并能还原对应的规范读音。
- 多音字、多音词或同一文字对应多条读音时，不得只给一个无说明的汉字题面：
  应显示本题采用的标准拼音，或者在无法可靠消歧时排除该题。
- 字词继续按双音、三音、四音、单音顺序分组；每组五题必须互不重复。
- 短句必须保留完整、连续、无遗漏的动态组句分段路径，并过滤明显不完整、
  不自然或仅靠异常低频部件成立的条目。
- 同一进程内切换变长、等长、省键方案时不得重新抽题；重新启动才生成新题组。
- 增加抽题完整性、读音可还原性、重复抑制和三模式答案一致性测试。

验收标准：任何一道题都能回答“为什么目标编码是这一串”，不能出现只看题面却
存在两个同样合理答案的情况。

### 2.2 四音元分段判错

- 不再只报告“整串正确／错误”，应把输入与首音、呼音、主音、末音四个位置对齐。
- 明确显示首个错误位置、对应音元名称、稳定音元 ID、目标物理键和实际输入键。
- 对分段练习、编码练习、字词练习和短句练习复用同一套诊断结构；字词与短句
  还要指出错误位于第几个音节。
- 变长和省键模式存在合并或省略时，诊断必须依据规范四音元序列与模式投影关系，
  不能把合法省略误判成缺键。
- “显示答案”应能逐级提示：先提示错误音节，再提示错误音元，最后才显示完整答案。

验收标准：单键错误、漏键、多键和跨音节错位都有稳定测试，使用者无需自行比较
两条长编码就能找到错误位置。

### 2.3 独立学习记录与自适应复习

- 记录每个稳定音元 ID、干音类别、正式音节和常用字词的答题次数、正确次数、
  连续正确次数、最近错误位置和反应时间。
- 建立“新题、学习中、待复习、已掌握”四种状态；错题提高近期出现概率，连续
  正确的题目逐渐延长复习间隔。
- 随机抽题升级为受约束调度：兼顾薄弱项、长期未练项、音元覆盖率、难度和近期
  重复抑制，而不是只在高频池中均匀随机。
- 提供本组重新练习、只练错题、今日复习和清空练习记录。
- 练习记录使用练习器自己的版本化数据文件，保存于
  `%APPDATA%\PIME\YimeTrainer`；不得读取、复用或修改 Rime 用户词典、用户频次、
  正式学习记录和屏蔽词表。

验收标准：关闭并重新打开练习器后，薄弱项和掌握状态仍然存在；清空练习记录只
删除练习器数据，不触碰任何正式输入数据。

### 2.4 循序课程与阶段门槛

- 提供一条默认学习路线：音元认键 → 首音／干音分段 → 单音节编码 → 双音词语
  → 三、四音词语 → 短句连续输入 → 真实候选实战。
- 每阶段明确题目范围、是否默认显示答案、建议练习量和进入下一阶段的条件。
- 新用户首先练少量分组，不得一开始直接面对全部 57 个音元或 1729 个音节。
- 默认门槛先采用可配置规则，例如达到规定题量且正确率不低于 90%；规则须允许
  根据试用结果调整，不能把未经验证的阈值写死在课程数据之外。
- 允许熟悉体系的使用者跳转到任意练习，但界面应保留“继续上次课程”的主入口。

验收标准：首次使用者无需理解内部分类文件，也能按程序给出的顺序完成第一轮
学习；熟练使用者仍可直接选择分组练习。

### 2.5 真实输入迁移与候选操作练习

- 增加独立的“实战练习”阶段，覆盖连续编码、候选选择、候选翻页、句中分段改选
  和修正后整句提交。
- 候选选择必须遵守 Yime 固定规则：裸数字始终是组成键，候选序号只使用
  `Shift+1` 至 `Shift+9`，候选标签保持 `⇧1` 至 `⇧9`。
- 练习不得直接使用正式 Rime 用户库。优先采用隔离的临时训练配置和临时学习库；
  如果隔离条件尚未满足，只能做候选行为模拟，不得以污染正式学习数据为代价。
- 实战题应复用字词、短句题库和句中改选证据，不再另外维护一套手写编码。
- 至少覆盖 x64 Notepad、Codex IDE 和 x86 SysWOW64 charmap 三宿主的训练链路验收。

验收标准：完成编码练习的使用者能够在不改变正式用户学习数据的前提下，练会从
连续输入到选词、改选和上屏的全过程。

## 3. 完整版之前仍需补齐的内容

以下项目可以在上述硬门槛之后分批实现，但在练习器宣称“完整”之前不能永久缺席。

### 3.1 指法信息

- 为每个物理键补充左／右手、具体手指和基准键关系。
- 音元练习除显示目标键外，还应显示应使用的手指。
- 增加相邻键、同指换键和左右手交替的专项练习。

### 3.2 听觉锚点与音频

- 保持 `audio` 可缺省，缺少音频时全部文字练习仍可进行。
- 音频来源必须具有明确授权或由项目自行制作，不能从公开教学材料直接切分后发布。
- 先覆盖 57 个音元的代表音值，再考虑音节、对比辨听和听音击键练习。
- 音频是教学辅助，不得被当作规范语音学结论或唯一正确发音。

### 3.3 学习报告

- 按音元、干音类别、首音组、音节和输入方案显示正确率与平均反应时间。
- 显示最常见的错误替换关系，而不只显示总正确率。
- 支持本地导出和清空；默认不联网，不收集用户输入内容或个人数据。

## 4. 明确不做的捷径

- 不把人工挑选少数示例重新作为主要课程内容。
- 不用纯随机抽题冒充自适应学习。
- 不复制第二套拼音、音元、布局或三模式编码表。
- 不通过正式用户词库或学习频次推测练习难点。
- 不为练习方便而改动 PIME、Rime 候选分页所有权或裸数字组成键规则。
- 不在没有隔离训练库时直接进行会污染正式学习记录的实战训练。

## 5. 推荐实施批次

1. 先完成题目消歧、读音展示和抽题质量门禁。
2. 实现统一的四音元／跨音节判错结构和逐级提示。
3. 增加独立学习记录、错题调度和“继续上次课程”。
4. 在上述数据稳定后加入阶段课程与解锁规则。
5. 最后接入隔离的真实候选实战，再逐步补充指法、音频和学习报告。

每个批次都必须保持三模式测试、课程完整性测试和对 PIME/Rime 正式数据的只读门禁。
