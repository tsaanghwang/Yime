## 维护入口

18u 现有无条件拒绝门不得简单删除。新的原生维护入口必须固定所执行脚本和包载荷字节，核对实际原生架构、同一用户 SID、管理员令牌及受保护路径；受保护暂存中的文件在调用受检 PowerShell 期间保持只读句柄。原生 shell 必须由其完整路径、架构、签名及核准哈希识别，不从 PATH 提升任意脚本。

制包时核验本机已安装的微软 ARM64 PowerShell 签名，复制完整运行时、模块与许可证到包内 `maintenance/powershell/`，逐文件纳入编译绑定清单。安装只执行受保护暂存中的固定 shell，不依赖 WindowsApps 的更新后路径、PATH 或其他产品。

Rime/PIME 与 18u 安装后的维护副本属于各自产品，位于 `%ProgramFiles%\Yime Maintenance\<product>\<plan SHA>`；系统应用列表指向其中的原生维护程序，避免卸载时锁住正在删除的产品目录。标准 YimeCore 使用自身目录中的 `.setup\Setup.ps1`。失败暂存保留证据，重试创建新的临时目录，完整验证后原子发布。此副本仅为独立维护依赖，不恢复已退休事务链。
