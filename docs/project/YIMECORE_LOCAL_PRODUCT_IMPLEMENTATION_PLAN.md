## 3. 设计默认值与不做事项

### 3.1 尽量原位晋级，不制造无必要迁移

活动本机产品的 x64/x86 TSF 表面共同使用 CLSID `{E40FA752-BB96-461D-A51D-F40EB437EC65}` 和 Profile `{126F54C6-E9B1-4E22-8652-03224CBD49F9}`。旧 CLSID `{41EC6C9B-E8D2-4E1E-9E7C-5CA3DAF0F66B}` 与 Profile `{607895A8-9504-4A2E-9BB1-2C159E3A1757}` 保留给历史封存试验。升级事务先完整保存旧 machine/user TIP 子树及 payload 引用，再按包描述符移除当前身份注册并注册“音元拼音”；不得改写或执行旧身份二进制。

现有数据目录、日志 source ID、学习命名空间和稳定内部文件名继续保留；目录或内部名称含 Trial/Experimental 不代表运行依赖 Rime。产品描述集中管理显示名称、活动 GUID、冻结旧 GUID、程序相对路径、数据版本和支持范围。本次只迁移显示身份，不迁移用户数据命名空间。

第一包可以保留已验证的二进制文件名，先解决自包含和维护一致性，不以全仓重命名作为验收要求。

### 3.2 新包本机 x64/x86 TSF 与冻结旧身份注册兼容

正常本机产品载荷包含 x64 Runtime/Broker/工具以及由当前源码和身份构建的 x64、x86 TSF 表面；x86 只服务本机 WOW64 32 位应用。本机 local.12/local.13 包线不混入 ARM64；单独平台线目前只有交叉构建／构建接线和合成状态，没有 ARM64 原生执行。旧试验包归档中的旧身份文件继续原样保留并带来源哈希。

当前冻结 x86 注册可能仍引用旧安装根：原位晋级不能把该根当作普通旧版本删除。维护计划必须静态枚举引用，标记为受保护的兼容保留根；本阶段不修改冻结注册，也不执行冻结注册工具。留存不等于支持或测试通过。

为新产品定义单独、严格的本机双 TSF 架构清单契约，不通过删除旧 E6-C 的文件检查来让残缺包“通过”。除 `x86/` 下三个 TSF PE 必须为 I386 外，Runtime、Broker 和工具仍必须为 AMD64；未知清单、漏列文件、越界或重复路径、错误架构和哈希错误一律拒绝。

### 3.3 本轮明确不做

- 不卸载生产 Rime/PIME，不更改默认输入法；默认切换与生产退役须另行明确请求。
- 不把双产品开发调整变成两套等量重写或互相绑定发布；先做独立产品合同与隔离测试，之后另行安排共存安装实证和薄选择入口，不在本轮文档调整中执行安装事务。
- 不改核心实现语言，不重做已通过的核心算法研究；不为非阻塞微基准比值反复优化。
- 不扩大语境音变规则范围，不把已有受审定功能全部重写；已有能力按当前范围保留。联网自动同步、额外离线同步产品功能不进入本轮；备份恢复不是同步功能。
- 主流 x86-64 与 ARM64 的独立试验可与本机 L5/L6 同步推进；不采购或租用机器，不用跨编译替代实机验收；x86 仍指本机 WOW64 应用宿主。
- 不关闭系统签名检查或修改应用权限以运行未签名包；本机如被安全策略实际阻止，报告准确限制。

## 4. 实施顺序与验收出口

依赖顺序：L1 → L2 → L3 → L4 → L5 → L6。每一步有明确产物，失败只退回受影响步骤，不从 E0 重来。

| 阶段 | 实施内容 | 完成出口 |
|---|---|---|
| L1 固定身份与源码基线 | 产品描述、兼容身份清单、源码内容哈希、版本约定、功能保留清单 | 能明确“构建了哪份源码、使用哪些数据、管理哪些注册项”；用户工作区修改未丢失 |
| L2 自包含 x64 构包 | 从空 staging 构建 TSF/Broker/工具，显式获得索引/资源，打包全部维护依赖 | 不读取已安装试验包也能生成完整产品包，依赖审计和 x64 测试通过 |
| L3 产品安装维护入口 | 首装/升级/卸载、原位晋级、备份恢复、系统视图校验、权限分离 | 仓库外运行包内命令可维护产品；不存在“必须运行仓库新版脚本才能修好”的缺口 |
| L4 候选包实机验收 | 固定 RC，完成受影响功能、迁移/回退、自身重装、登录自启动 | 新产品版本对应的本机验收证据完整，生产与用户数据保留 |
| L5 日常使用与有限宿主扩展 | 在本机常用应用持续使用，只修实际阻塞及回归 | 开发者确认可日常使用，已知限制与复现方式明确 |
| L6 本机版本封存 | 冻结包、源码身份、数据版本、帮助与恢复介质，汇总本机就绪结果 | `local_product_ready=true`；公开发行仍单独判定，其他机型仍待解冻审批 |
