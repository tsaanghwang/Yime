Yime “元”试验版

这是与正式版 PIME/Rime 独立运行的 YimeCore 试验环境。安装文件位于独立的 Program Files 包目录，个人状态位于 %LOCALAPPDATA%\YimeCore Experimental Trial。

候选与输入

  • 数字键始终用于继续组码，不直接选择候选。
  • 使用 Shift+1 到 Shift+9 选择候选，候选标签显示为 ⇧1 到 ⇧9。
  • 工具中心中的“设置工具”用于调整试验版候选和工具栏状态。

工具中心

“键盘布局”会在 Trial 状态目录中生成并校验 full、variable、shorthand 三套独立索引，然后重启 Trial runtime。它不会部署 Rime，也不会修改正式版用户目录。

“用户词库”“反查编码”和“指法练习”会跟随当前 Trial 布局。“诊断工具”只收集 Trial 安装、runtime、Broker、状态文件和 Trial 日志。

数据与恢复

“试验版用户数据”可打开个人状态目录。“试验版共享数据”可查看当前安装包的只读基础数据。自定义键盘布局保存在个人状态目录的 layout 子目录中。

遇到问题时先打开“诊断工具”，刷新并复制匿名化结构化报告，再参照“用户反馈”提交必要信息。
