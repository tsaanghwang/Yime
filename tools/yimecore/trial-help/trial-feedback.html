用户反馈

反馈“元”试验版问题时，请说明问题发生在 Trial，而不是正式版“音”。

建议附带

  • Windows 版本、应用名称，以及问题发生的大致时间。
  • 当前输入模式：variable、full 或 shorthand。
  • 可稳定复现的按键步骤、预期结果和实际结果。
  • 从“工具中心 → 诊断工具”复制的匿名化结构化报告。

隐私提示

诊断工具默认匿名化路径，并且不会包含原始日志摘录。原始日志可能包含经过输入法处理的文本；只有在确认内容并确有必要时才启用“包含原始日志摘录”，提交前请再次检查。

不要提交密码、验证码、私密文本、完整用户目录或未经检查的日志。

隔离核对

若问题涉及键盘布局、词库或诊断，请注明正式版数据是否同时发生变化。Trial 工具的正常行为不应修改正式版 PIME/Rime 数据和日志目录。
